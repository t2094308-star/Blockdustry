# 研究：物品源方块与资源栏避让 Jade

> 目标：新增 Mindustry 沙盒「物品源」（item-source）方块（无限凭空产煤/石墨等资源），并把顶部资源栏移到右上角避让 Jade tooltip 喵。
> 源码根：MC 侧 `D:\Blockdustry\仓库\src\main\java\com\blockdustry\`，Mindustry 贴图源 `D:\Blockdustry\Mindustry\core\assets-raw\sprites\blocks\sandbox\` 喵。

## 一、任务一：物品源方块（item_source）

### 1.1 设计

- **方块**：`blockdustry:item_source`，1×1 建筑，强度 0.5（调试方块易碎）喵。
- **方块实体**：`ItemSourceBlockEntity extends BlockdustryBuildingEntity`，每模组 tick（`tickAnchor`）向相邻四邻域可接收的传送带/建筑 `dumpItem(product)` 一个物品喵。
- **产物**：默认煤（`Items.COAL`），可右键循环切换：煤 → 石墨 → 硅 → 铅 → 煤喵。
- **纯产器**：覆写 `acceptItem`/`handleItem` 恒返回 false，不接收任何外部物品（忠于 Mindustry source 不吃料）喵。
- **贴图**：取自 Mindustry `sandbox/item-source.png`（32×32），拷为 `textures/block/item_source.png` 喵。

### 1.3 关键实现细节

#### 方块实体核心逻辑

```java
// 每模组 tick：卸一个产物给相邻传送带/建筑；无接收方则丢弃（沙盒语义）喵
@Override
protected void tickAnchor() {
    dumpItem(product);
}

// 循环切换产物：煤→石墨→硅→铅→煤喵
public void cycleProduct() {
    if (product == Items.COAL) product = BlockdustryBlocks.GRAPHITE.get();
    else if (product == BlockdustryBlocks.GRAPHITE.get()) product = BlockdustryBlocks.SILICON.get();
    else if (product == BlockdustryBlocks.SILICON.get()) product = BlockdustryBlocks.LEAD.get();
    else product = Items.COAL;
    setChanged();
    if (level != null && !level.isClientSide) {
        level.sendBlockUpdated(worldPosition, getBlockState(), getBlockState(), 3); // 同步客户端喵
    }
}
```

- `dumpItem(Item)` 是基类 `BlockdustryBuildingEntity` 的受保护方法：遍历本建筑「全占地四邻域」的候选格，按轮询指针（Mindustry cdump）找第一个 `acceptItem` 通过的 `BlockdustryItemSink` 移交喵。物品源（1×1）直接复用，无需自建库存喵。
- 团队判定：`dumpItem` 内部用 `sourceAt(cell)` 得到来源格（本格 BE），`sink.acceptItem` 会检查 `getTeam().canInteract(source.getTeam())`。物品源放置时经 `BlockdustryTeamHandler.onBlockPlaced` 继承放置者队伍，因此与玩家同队传送带可正常交接喵。

#### 右键切换（1.21.1 空手交互）

MC 1.21.1 的 `Block` 已无 `use`，拆分为：
- `protected InteractionResult useWithoutItem(BlockState, Level, BlockPos, Player, BlockHitResult)`（空手）喵
- `protected ItemInteractionResult useItemOn(ItemStack, BlockState, Level, BlockPos, Player, InteractionHand, BlockHitResult)`（持物）喵

`ItemSourceBlock` 覆写 `useWithoutItem`，服务端切换产物并提示玩家：

```java
@Override
protected InteractionResult useWithoutItem(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hit) {
    if (!level.isClientSide) {
        if (level.getBlockEntity(pos) instanceof ItemSourceBlockEntity src) {
            src.cycleProduct();
            if (player instanceof ServerPlayer sp) {
                sp.sendSystemMessage(Component.literal(
                        "物品源产物已切换为: " + src.getProduct().getDescription().getString()), true);
            }
        }
    }
    return InteractionResult.sidedSuccess(level.isClientSide); // 客户端 SUCCESS 触发服务端包，服务端 CONSUME 收尾喵
}
```

#### 与 PowerNode 空手交互的冲突处理

`PowerNodeInteractHandler` 此前对「任何方块空手右键」一律 `setCanceled(true)`（两阶段连线用），会把物品源的空手右键也拦掉。故在 `onRightClick` 中增加早退分支：

```java
BlockEntity be = player.serverLevel().getBlockEntity(clicked);
if (be instanceof ItemSourceBlockEntity) return; // 物品源自处理，不拦截，交由方块 useWithoutItem 喵
```

这样既不动电力节点两阶段逻辑，也让物品源方块类自行管理交互喵。

#### 注册

- `BLOCKS.register("item_source", BlockdustryBlocks::itemSourceBlock)`，工厂方法返回 `new ItemSourceBlock(Properties, () -> ITEM_SOURCE_ENTITY.get(), 1)` 喵。
- `BLOCK_ENTITY_TYPES.register("item_source", () -> BlockEntityType.Builder.of((pos, state) -> new ItemSourceBlockEntity(pos, state), ITEM_SOURCE.get()).build(null))` 喵。
- 创造栏 `output.accept(ITEM_SOURCE_ITEM)` 喵。

### 1.4 使用方式

- 创造栏「方块工业」tab 拿取，或 `/give @s blockdustry:item_source` 喵。
- 放置后空手右键循环切换产物；把传送带/建筑摆到相邻格即可看到物品不断涌出喵。
- 默认产物煤，会喂给石墨压缩机（吃 2 煤产 1 石墨）验证「产出→输送→加工」整条链路喵。

## 二、任务二：资源栏避让 Jade tooltip

### 2.1 冲突根因

`client/CoreHudHandler.java` 资源栏原来画在**顶部居中**（`x0 = (screenW - panelW) / 2; y0 = 4`）。Jade 默认 tooltip 渲染在鼠标处、屏幕中上偏左，两者在玩家视角看向顶部/建筑时重叠喵。

### 2.2 方案选择

- **方案 A（采用）**：资源栏移到**右上角**，`x0 = screenW - panelW - 4`，保持 Mindustry「图标+数量」样式、黑 60% 背景、每行 4 项、非零项显示、K/M 缩写不变喵。
- **方案 B（备选，未采用）**：Jade 有公开回调 `snownee.jade.api.callback.JadeBeforeRenderCallback#beforeRender(IBoxElement, TooltipRect, GuiGraphics, Accessor<?>)`，可经 `IWailaClientRegistration.addBeforeRenderCallback` 注册，`TooltipRect` 携带 tooltip 矩形，据此动态下移/隐藏资源栏。但该回调渲染时序晚于 `RenderGuiEvent.Post`（HUD 已画完），且需每帧清标记，较脆弱；方案 A 更简单可靠喵。

### 2.3 改动

`CoreHudHandler.onRenderGui` 一处：

```java
// 右上角布局：贴右留 4px 边距，避开 Jade 默认 tooltip（鼠标处屏幕中上偏左）喵
int x0 = screenW - panelW - 4;
int y0 = 4;
```

其余样式逻辑（`itemW=56`、每行 4 项、黑背景 `0x99000000`、数量左对齐、K/M 缩写）完全不变喵。
