# 修改文档：钻头侧面贴图应用（重绘真正的侧面贴图）喵

> 记录钻头侧面贴图的完整过程、目标、踩过的 MC UV 语义坑与**贴图内容错误**教训，供后续参考喵。

## ⚠️ 核心问题：之前画的「侧面贴图」其实是顶面贴图的一部分喵

- 用户确认：当前 `drill_side.png`（64×64）与 `drill_side_preview.png`（512×512）的**内容根本不是侧面贴图，只是机械钻头顶面贴图（`drill.png` 合成图）的一部分**喵
- 教训：绘制侧面贴图必须先明确**侧面视角内容**（2×2 底座侧面 = 深色金属外壳、面板、螺栓/通风孔），不能拿顶面图案的局部当侧面喵
- **命名要详细**：贴图文件名应语义化（如 `drill_side.png` / `drill_side_base.png`），能一眼看出用途与部位喵

## 目标喵

重绘一张**真正的钻头侧面贴图**：2×2 机械钻底座侧面（3D 侧面视角）——深色金属外壳、中央面板、螺栓/通风孔/接缝，参考 Mindustry `mechanical-drill.png` 底座侧面视觉（不用顶面图案局部）喵。命名详细（`drill_side.png` 覆盖或 `drill_side_base.png` + 模型同步引用），尺寸方形（256/512 全不透明），uv 保持 `[0,0,16,16]`（MC 模型 UV 空间，勿改大）喵。

## 应用步骤喵

1. 重绘真正侧面贴图（侧面视角深灰金属外壳）→ 覆盖 `drill_side.png`（命名详细）
2. 钻头模型 `drill_{nw,ne,sw,se}.json` side/down face 引用 `#side`，uv `[0,0,16,16]`（勿改）
3. `runClient` 验证四侧显示真正的金属外壳侧面、无顶面图案残留、无杂乱

## ⚠️ 关键坑：MC 方块模型 UV 是 16×16 模型 UV 空间，不是贴图像素坐标喵

- MC 方块模型 face 的 `uv` 范围 **0..16**，`[0,0,16,16]` 即「取整张贴图」，MC 按贴图在方块 atlas 的位置自动映射喵
- **坑**：改成 `[0,0,64,64]` → MC 采样 atlas 左上 64×64 区域（钻石/金块等拼图）→ 侧面杂乱 + 卡顿喵
- **结论**：方块模型 UV 永远 `[0,0,16,16]`；贴图分辨率越高越清晰（512 安全，别超 1024）喵
