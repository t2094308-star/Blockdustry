# 子 Agent 阶段性产出目录喵

所有子 agent 的**阶段性产出**统一写入本目录（`D:\Blockdustry\仓库\docs\子agent`），命名 `{编号}_{任务名}.md`，格式如下喵。

## 统一产出格式喵

```markdown
# {任务名} 阶段产出喵

## 目标喵
{一句话说明本阶段目标}

## 结论/产出喵
{核心结论、代码片段、资源清单等}

## 占用与交接喵
- 占用文件: {已读/已写路径}
- 交接给: {上级 agent 或主会话；需要主会话做的整合动作}
- 风险/待人工排查: {如有}

## 异常喵
{无，或标准 JSON 异常日志}
```

## 标准 JSON 异常日志格式喵

```json
{
  "level": "error|fatal",
  "agent": "{agent 标识}",
  "task": "{任务登记文件路径}",
  "cause": "{一句话根因}",
  "file": "{涉及文件}",
  "recoverable": true/false
}
```

## 规则喵

- 只写本目录 + 任务登记目录，不直接改游戏源码（除非你的任务明确是「写独立新文件供主会话整合」喵）
- 探索类任务产出文档，实现类任务产出独立新文件 + 说明，主会话负责整合注册与编译喵
