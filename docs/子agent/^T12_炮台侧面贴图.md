# T12 炮台侧面贴图修复 产出喵

## 目标喵
修复所有炮台（turret 双管 / scatter 分裂）侧面贴图显示钻头侧面图案的问题：给炮台一块独立的深灰金属基座侧面贴图 `turret_side.png`，并让 `turret.json`/`scatter.json` 及其四象限变体的 side/down/particle 引用它，不再复用 `drill_side`。同时在用户目录按命名规范归档炮台贴图喵。

## 问题分析（改动前）喵
- `models/block/turret.json`、`scatter.json` 以及 `scatter_ne/nw/se/sw.json` 的 `textures.particle`、`textures.side` 全部指向 `blockdustry:block/drill_side`，`down` 面用 `#side` 继承 → 炮台六个面（除顶面外）贴的是钻头侧面图（机械钻头图案）喵。
- MC 模型 UV `[0,0,16,16]` 按「贴图 0~16 单位 = 整张贴图」映射，64×64 的 `drill_side.png` 整张（含机械钻头图案）会拉伸到方块侧面，故侧面显眼地是钻头图案喵。

## 本次改动喵

### 1. 新贴图 `textures/block/turret_side.png`（64×64 RGBA 全不透明）喵
- 风格：参考 Mindustry `bases/block-1.png`（duo 底座）与项目 `scatter_base`/`drill_side` 的深灰金属基座观感，干净平涂、不做旧喵。
- 内容：外缘倒角（顶/左高光 + 底/右暗边）、内嵌面板框、四角 5×5 铆钉、中部水平接缝 + 两根竖向筋条、中央八角螺栓（十字槽），整体深灰金属色板（约 `(100,102,115)` 主面板）喵。
- 校验：方形 64×64、RGBA、alpha 极值 `(255,255)` 全不透明喵。

### 2. 模型 JSON 引用修正（6 个文件）喵
`particle` 与 `side` 由 `blockdustry:block/drill_side` → `blockdustry:block/turret_side`；`down` 面走 `#side` 自动跟随喵：
- `models/block/turret.json`
- `models/block/scatter.json`
- `models/block/scatter_ne.json`、`scatter_nw.json`、`scatter_se.json`、`scatter_sw.json`

### 3. 用户目录归档（`D:\Blockdustry\像素图片绘制尝试\炮台\`）喵
按命名规范「炮台_编号_面_高清.png」（顶面=1/侧面=2）整理复制，双管（duo）与分裂（scatter）两系各一份喵：

## 校验结果喵
- `./gradlew compileJava --offline`：`BUILD SUCCESSFUL`（exit 0）喵。
- `./gradlew processResources --offline`：`BUILD SUCCESSFUL`，`build/resources/main/.../turret_side.png` 已同步（64×64 RGBA、全不透明）喵。

## 交接与建议喵
- 占用：上述贴图 + 6 个模型 JSON + 文档 + 用户目录归档喵。
