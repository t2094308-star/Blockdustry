# ^P1_批1A_A1 整合清单：junction（1×1）+ distributor（2×2）喵

> 迁移 Mindustry junction/distributor 到 Blockdustry（NeoForge 1.21.1）。本任务只写独立新文件，以下改动全部由主会话合并进共享文件喵。

## 0. 关键数据核对结论（最高要求「数据不串」）喵

已读 `Mindustry/core/src/mindustry/content/Blocks.java` + `Junction.java` + `Router.java` + `SerpuloTechTree.java`，核对结果与任务简报的**两处出入**（按原版实现）喵：

| 项 | 任务简报假设 | Mindustry 原版实测 | 本实现 |
|---|---|---|---|
| distributor 占地 | size 3（3×3） | **size 2**（`distributor = new Router("distributor"){{ size = 2 }}`） | **size 2** |
| distributor 贴图 | 96px | **64px**（`distributor.png` 64×64） | 拷 64px 原版 |
| distributor 类 | 有独立 Distributor 类 | 无，是 **Router 子类** | DistributorBlockEntity extends RouterBlockEntity |

- junction 参数（原版）：size 1、copper×3、health 30、speed 26、capacity 6、buildCostMultiplier 3。
- distributor 参数（原版）：size 2、lead×4 + copper×4、buildCostMultiplier 3、Router 语义（收 1 件、轮询卸四周）。
- 科技树原版：`conveyor→junction→router→distributor`；本任务按简报给 `junction/distributor` 都挂 `conveyor`（见 §4）。
- **若协调者坚持 distributor 改 size 3**：改动点 = Registrar 尺寸参 2→3、item size 2→3、blockstate 需 9 个 corner 模型（nw/n/ne/w/c/e/sw/s/se）、item 模型改挂 3×3 全贴图模型、`registerGroupMaxHp` 参 2→3。本实现按原版 size 2 交付喵。

## 2. Blockdustry.java（主类） 喵

在构造器 `ElevatorBlocks.register(modEventBus);` 之后加一行：

```java
import com.blockdustry.distribution.JunctionRegistrar;
// ...
JunctionRegistrar.register(modEventBus);
```

## 3. BlockdustryBlocks.java 喵

### 3.1 物流创造栏 tab（DISTRIBUTION_TAB.displayItems）喵

`output.accept(ElevatorBlocks.ELEVATOR_ITEM);` 之前（按原版顺序 conveyor→junction→router→distributor）插入：

```java
output.accept(JunctionRegistrar.JUNCTION_ITEM);
output.accept(JunctionRegistrar.DISTRIBUTOR_ITEM);
```

需新增 import：`import com.blockdustry.distribution.JunctionRegistrar;` 喵。

### 3.2 整组血量（registerBlockHealthDefaults）喵

`registerGroupMaxHp` 行追加（distributor size 2；junction 1×1 无需组血量）：

```java
registerGroupMaxHp(JunctionRegistrar.DISTRIBUTOR.get(), 2);
```

## 4. ResearchNodes.java（科技树） 喵

`ResearchNode.builder("router")` 之后（conveyor 子节点区）加 2 节点（简报要求 parent=conveyor）：

```java
// —— 物流：junction/distributor（Mindustry 原版 conveyor→junction→router→distributor，此处按任务挂 conveyor）——
ResearchNode.builder("junction")
        .parent("conveyor")
        .unlockBlock(JunctionRegistrar.JUNCTION.get())
        .buildRequirement(copper, 3)   // Mindustry junction = 铜×3 喵
        .build(),
ResearchNode.builder("distributor")
        .parent("conveyor")
        .unlockBlock(JunctionRegistrar.DISTRIBUTOR.get())
        .buildRequirement(copper, 4)   // Mindustry distributor = 铜×4 铅×4 喵
        .buildRequirement(lead, 4)
        .build(),
```

需新增 import：`import com.blockdustry.distribution.JunctionRegistrar;` 喵。
