# ^T49 修理器(mender)维修特效 + 力墙投影(force-projector)护盾特效 原版研究喵

> 数据核对对象：`Mindustry/core/src/mindustry/world/blocks/defense/MendProjector.java`、`ForceProjector.java`、
> `Fx.java`（healBlockFull/shieldBreak/forceShrink/absorb）、`Blocks.java` L1919/L1964、`SerpuloTechTree.java`。
> 结论：原版 mender **没有射向目标的"维修光束激光"**，维修视觉 = 目标块 `Fx.healBlockFull` 闪烁 + 自身顶部呼吸/方框脉冲；
> force-projector 护盾是**水平六边形**（Fill.poly/Lines.poly），非"球体圆顶"。均按原版忠实移植，未自行编造特效喵。

## 一、mender 维修特效逐条记录喵

### 1. 目标块闪烁 `Fx.healBlockFull`（核心视觉）喵
- 触发：`MendProjector.MendBuild.updateTile` 每次维修，对每个被修建筑 `Fx.healBlockFull.at(other.x, other.y, other.block.size, baseColor, other.block)`喵
- 定义（Fx.java L2781-2787，寿命 20 tick）：
  - `mixcol(e.color, 1f)` —— 用 baseColor 全量混色喵
  - `alpha(e.fout())` —— 淡出喵
  - `Draw.rect(block.fullIcon, e.x, e.y)` —— 画被修方块的全图标（尺寸 = block.size）喵
- 视觉本质：**被修目标方块以维修色 baseColor 染色、20 tick 淡出**，不是光束/激光喵
- Blockdustry 3D 适配：目标块顶面白色 quad 染 baseColor、alpha=fout×0.6、20 tick（MenderBlockEntityRenderer.drawRepairFlash）喵

### 2. 自身顶部呼吸 `topRegion`（MendProjector.draw L145-159）喵
- `Draw.color(baseColor, phaseColor, phaseHeat)` —— 有硅 phaseHeat 时向 phaseColor 过渡（mender phaseColor=baseColor，故不变色）喵
- `Draw.alpha(heat * Mathf.absin(Time.time, 50/PI2, 1f) * 0.5f)` —— 热值×正弦呼吸，alpha 峰值 0.5 喵
- `Draw.rect(topRegion, x, y)` —— 顶部贴图（mender-top.png）喵
- Blockdustry 适配：mender_top 贴图 1×1 quad，alpha=heat×|sin(t×2π/31.8)|×0.5，染 baseColor #84f491 喵

### 3. 旋转方框脉冲（MendProjector.draw L155-156）喵
- `f = 1f - (Time.time/100f) % 1f`（周期 100 tick）喵
- `Lines.stroke((2f*f + 0.2f) * heat)`喵
- `Lines.square(x, y, min(1f + (1f-f)*size*tilesize/2f, size*tilesize/2f))` —— 半径从 1 脉冲到 4（Mindustry 单位，=0.125→0.5 格）喵
- Blockdustry 适配：45° 菱形细条线框，半径随 f 脉冲，染 baseColor，厚度 0.04 格（3D 加粗保证可见）喵

### 4. 维修音效 `Sounds.healWave`（0.5 音量）喵
- Blockdustry 无环境音系统，省略（与批1C 冒烟/窑炉一致）喵

## 二、force-projector 护盾特效逐条记录喵

### 1. 护盾多边形 `drawShield`（ForceProjector.ForceBuild.drawShield L307-330）喵
- `radius = realRadius()` = `(radius + phaseHeat×phaseRadiusBoost) × radscl`喵
- `Draw.color(team.color, Color.white, Mathf.clamp(hit))` —— 受击 hit 闪白喵
- `renderer.animateShields==true`：`Fill.poly(x, y, sides=6, radius, shieldRotation=0)` 实心六边形，z=Layer.shields+0.001×hit 喵
- 否则：`Lines.stroke(1.5)` + `Draw.alpha(0.09 + clamp(0.08×hit))` + `Fill.poly` 实心低透明 + `Lines.poly` 线框喵
- **形状是水平六边形（6 边，顶点从角度 0 起）**，非球体/圆顶喵
- Blockdustry 适配：水平六边形（x-z 平面）画在建筑中心基座上 1.5 格，实心盘 alpha≈0.09 + 线框细条 0.06 格；顶点公式与 `insideHex` 点包含同构（顶点从 0° 起每 60°）喵

### 2. 蓄力 top 加色（ForceProjector.draw L294-302）喵
- `buildup > 0` 时：`Draw.alpha(buildup/shieldHealth × 0.75)`、`Layer.blockAdditive`、`Blending.additive`、`Draw.rect(topRegion)`喵
- Blockdustry 适配：force-projector-top 贴图铺 3×3，alpha=buildup/750×0.75，translucent 正常混合（MC 无 additive）喵

### 3. 破碎 `Fx.shieldBreak`（寿命 40 tick，Fx.java L2807-2816）喵
- 触发：`buildup ≥ shieldHealth + phaseShieldBoost×phaseHeat` 时 `broken=true`，`shieldBreakEffect.at(x, y, realRadius(), team.color)`喵
- `Lines.stroke(3×fout)`、`Lines.poly(x, y, 6, e.rotation + e.fin())` —— 六边形线框半径从 e.rotation（=realRadius）扩 +1 Mindustry 单位并淡出喵
- Blockdustry 适配：线框从破碎时半径扩散 1.5 格、alpha=fout、40 tick（drawBreak）喵

### 4. 移除收缩 `Fx.forceShrink`（寿命 20 tick，Fx.java L1362-1373）喵
- 触发：`onRemoved` 时 `Fx.forceShrink.at(x, y, radius, team.color)`，六边形半径收缩到 0 淡出喵
- Blockdustry 省略：MC 中 BE 移除后不再渲染，无法呈现移除动画（整合清单已知省略）喵

### 5. 拦截子弹 `Fx.absorb`（寿命 12 tick，Fx.java L1356）喵
- 触发：`absorbEffect.at(bullet)` 每拦截一颗子弹喵
- Blockdustry 适配：白色 billboard 光点，alpha=fout、半径 0.12×(1+fout) 格，12 tick（drawAbsorbPoints）喵

## 三、机制要点（非特效）喵
- 拦截：`Groups.bullet.intersect` 六边形范围 → Blockdustry 用 `level.getEntitiesOfClass(Projectile)` + `insideHex` 点包含喵
- 蓄力冷却：`buildup -= (broken?cooldownBrokenBase:cooldownNormal)×delta`；broken 且 buildup≤0 → 恢复喵
- 破碎阈值：`shieldHealth + phaseShieldBoost×phaseHeat`（相织布加 400 护盾强度）喵
- 冷却液 ConsumeCoolant：本 mod 无液体系统，省略（cooldownNormal 保留）喵

## 四、结论喵
- mender 无"光束"，已忠实移植 healBlockFull（目标块闪烁）+ topRegion 呼吸 + 方框脉冲喵
- force-projector 是水平六边形护盾，已移植护盾绘制 + 蓄力 top + 破碎 + 拦截光点喵
- forceShrink（移除收缩）因 MC 移除后不渲染而省略，已在整合清单上报喵
