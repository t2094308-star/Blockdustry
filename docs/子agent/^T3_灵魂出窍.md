# T3 灵魂出窍 (Freecam) 迁移研究阶段产出喵

## 目标喵
研究 tweakeroo 的「灵魂出窍/freecam」功能实现，评估将其迁移到方块工业 Blockdustry（NeoForge 1.21.1，Mojang 官方映射）的可行性，给出技术方案与风险清单喵。

### 1.2 核心原理（相机实体方案）喵

tweakeroo 不做「改一个相机坐标」，而是造一个**假的 LocalPlayer 实体**（`CameraEntity`），把它塞进 `Minecraft.setCameraEntity()` 成为渲染相机喵。原版整个渲染管线天然以「相机实体」为中心：`Camera.setup()` 从相机实体取位置与朝向、区块加载以相机实体为中心、雾效/裁剪都跟随它喵。

- 玩家身体原地保留：freecam 开启时用 `DummyMovementInput` 冻结 `LocalPlayer.input`，并在 `Entity.turn()` 里取消玩家转向，所以本体不动喵。
- 相机自由飞行：`CameraEntity` 不进实体列表、不 tick，由 `MiscTweaks.onTick()` 手动调 `movementTick()` 读 WASD/跳跃/潜行/疾跑，按衰减算法（`calculatePlayerMotionWithDeceleration`，加速斜坡 0.15、减速因子 0.4）算出速度，用 `move(MoverType.SELF, delta)` 移动相机喵。
- 相机转向：复用玩家每帧的 `turn()` 调用——mixinn 到 `Entity.turn()` HEAD，freecam 时把 `(dx, dy)` 乘 0.15 叠加到相机实体 yaw/pitch，再 `ci.cancel()` 阻止玩家本体转向喵。
- 移动速度：`getMoveSpeed() = base * 10`，base 默认 0.07（可被 FLY_SPEED 配置覆盖）；疾跑时前进分量 ×3 喵。
- 玩家身体渲染：freecam 期间把相机实体设为非本地玩家，原版会按「分离相机」逻辑把客户端玩家也渲染出来；tweakeroo 再用 `Camera.entity()` 伪造 + `isSpectator()` 置位兜底，确保本体模型可见喵。
- 区块重建：相机离开原区块后，原版服务器不会为相机发新区块，需在相机移动时用 `markChunksForRebuild()` 把新出现的边缘区块标脏重建，否则地形消失喵。

### 1.3 关键机制细节喵

- 创建相机：`camera.setPosRaw(玩家位置 + y/0.125)`，`setDeltaMovement(ZERO)`，`noPhysics=true`，`isSpectator()` 返回 true（让相机渲染按观战处理）喵。
- 相机实体 `getId()` 返回原相机实体（玩家）的 id，兼容部分 mod 的实体 id 校验喵。
- 退出时恢复：`mc.setCameraEntity(原实体)`，恢复 `mc.smartCull`（原版实体智能剔除开关），并 `markChunksForRebuildOnDeactivation()` 重绘回玩家附近的区块喵。
- 旋转归一：`CameraUtils.getCameraYaw()/getPitch()` 用 `Mth.wrapDegrees` 归一化喵。

## 二、NeoForge 1.21.1 可行性评估喵

### 2.1 平台差异（必须先看）喵

- tweakeroo 参考工程是 **Fabric + Loom + Yarn 映射**（`Identifier`、`LevelExtractor`、`Hud` 等），且是 1.21.5 风格的新渲染架构喵。
- Blockdustry 是 **NeoForge 1.21.1 + 官方 Mojang 映射**（`ResourceLocation`、`Gui`、`MultiBufferSource` 等），版本落后于参考工程，部分类（如 `LevelExtractor`）在 1.21.1 不存在，需映射到 `LevelRenderer`/`GameRenderer` 的等价注入点喵。
- **概念 1:1 可迁移**，类名/方法签名需逐一按 Mojang 映射改名喵。

### 2.2 NeoForge 1.21.1 可用 hook 对照喵

| 参考实现（Yarn）喵 | 1.21.1 Mojang 对应喵 | 是否可用喵 |
|---|---|---|
| `Minecraft.setCameraEntity()` | `Minecraft.setCameraEntity(Entity)` / `getCameraEntity()` 同存在 | ✅ 推荐主路径喵 |
| `Minecraft.smartCull` | 同名字段存在 | ✅ 直接读写喵 |
| `Entity.turn(double, double)` | 同签名存在 | ✅ 相机转向 mixin 目标喵 |
| `LocalPlayer.input` / `ClientInput` / `KeyboardInput` | 同存在（`net.minecraft.client.player.*`） | ✅ 假输入冻结身体喵 |
| `LocalPlayer.isControlledCamera()` | `LocalPlayer.isControlledCamera()` 存在 | ✅ 保持输入/渲染被控制态喵 |
| `Camera.setup()` | `Camera.setup(BlockGetter, Entity, boolean, boolean, float)` | ✅ 备选方案 mixin 目标喵 |

### 2.3 关键可行性结论喵

1. **玩家身体保留**：✅ 完全可行。冻结 `LocalPlayer.input` + 拦截 `Entity.turn()`，本体原地站着，视角飞走，即「灵魂出窍」喵。
2. **世界渲染以相机为中心**：✅ 原版本就以 `getCameraEntity()` 为渲染中心，相机实体方案自动获得区块裁剪/雾效/渲染顺序喵。
3. **不需要服务端配合**：✅ 纯客户端，服务器无感知（区块不随相机移动，需本地标脏重建兜底）喵。
4. **与上帝视角区别**：F5 第三人称相机始终锚定玩家、绕玩家旋转；freecam 相机实体完全解耦、可离开玩家飞行，且玩家身体渲染为独立可见实体喵。
5. **NeoForge 事件能否替代 mixin？** ❌ 不能完全替代。NeoForge 没有「改相机位置」的事件（`ViewportEvent.ComputeCameraAngles` 只改角度不改位置、不改渲染中心），区块/裁剪中心跟随相机实体是写死行为；所以**必须走 mixin + `setCameraEntity()`** 方案喵。

## 三、迁移技术方案喵

### 3.1 推荐方案：相机实体（tweakeroo 移植）喵

在 `com.blockdustry.client.freecam` 新增以下文件，主会话负责注册 mixin 与事件喵：

| 新文件喵 | 内容喵 |
|---|---|
| `FreeCamCamera.java` | `extends LocalPlayer`，构造用 `LocalPlayer(ClientLevel, GameProfile)` 两参构造 + `setConnection(player.connection)` 补连接；`isSpectator()` 恒真；`getId()` 返回真实玩家 id；静态单例与 `setCameraState(boolean)` 喵 |

| `mixin/FreeCamMixinEntity.java` | `@Mixin(Entity.class)`，`@Inject(method="turn", at=HEAD, cancellable)`：`(Object)this == mc.player && freecam` 时 `camera.setCameraRotations(yaw+dx*0.15, clamp(pitch+dy*0.15))` 并 `ci.cancel()` 喵 |
| `mixin/FreeCamMixinLocalPlayer.java` | `@Mixin(LocalPlayer.class)`：`tick()` HEAD/RETURN 换假输入；`swing()` HEAD 取消；`isControlledCamera()` 恒真喵 |

| `mixin/FreeCamMixinGui.java` | `getCameraPlayer()` 返回真实玩家；按配置隐藏热键栏/状态条喵 |
| `mixin/FreeCamMixinLevelRenderer.java` | 相机移动时标脏边缘区块；渲染期间置位「幽灵渲染」标志让本体可见喵 |
| `FreeCamInput.java` | `extends KeyboardInput` 空 `tick()`，冻结身体喵 |
| `FreeCamHooks.java` | `@EventBusSubscriber` 客户端：`ClientTickEvent.Post` 驱动移动；注册 `KeyMapping`（MOD 总线 `RegisterKeyMappingsEvent`）与开关回调喵 |

### 3.2 备选方案：`Camera.setup()` 纯视角覆盖喵

- mixin `Camera.setup()`，在函数内改写 `this.position`、`this.yaw/pitch` 为自由相机状态（存一组静态坐标）喵。
- 优点：不碰实体系统、不建假实体，代码量小喵。
- 缺点：射线拾取（`Minecraft.pick()` 从相机实体射线）、实体渲染顺序、雾效/区块裁剪中心、`shouldRenderEntity` 等一系列以相机实体为锚的逻辑全要额外混入修正，容易漏；**不推荐**，仅当「绝对不想动实体」时考虑喵。

### 3.3 关键代码思路（签名级）喵

```java
// FreeCamCamera 核心：创建与启用（Mojang 映射 1.21.1）喵
public final class FreeCamCamera {
    private static FreeCamCamera camera;            // 相机实体单例喵
    private static Entity originalCamera;           // 原相机实体（真实玩家）喵
    private static boolean smartCullOriginal;       // 恢复用喵
    private static Vec3 motion = Vec3.ZERO;         // 相机速度喵

    private FreeCamCamera(Minecraft mc) {           // 构造相机实体喵
        super(mc.level, mc.player.getGameProfile());
        this.noPhysics = true;                      // 无碰撞喵
        setConnection(mc.player.connection);        // 补连接引用，避免 NPE 喵
        setPosRaw(mc.player.getX(), mc.player.getY() + 0.125, mc.player.getZ());
        setYRot(mc.player.getYRot());
        setXRot(mc.player.getXRot());
        setDeltaMovement(Vec3.ZERO);
    }

    public static void setEnabled(boolean enabled, Minecraft mc) {
        if (enabled && camera == null) {
            camera = new FreeCamCamera(mc);
            originalCamera = mc.getCameraEntity();
            smartCullOriginal = mc.smartCull;
            mc.setCameraEntity(camera);             // 关键：换成相机实体喵
            mc.smartCull = false;                   // 关闭实体智能剔除喵
        } else if (!enabled && camera != null) {
            mc.setCameraEntity(originalCamera);     // 恢复真实玩家为相机喵
            mc.smartCull = smartCullOriginal;
            FreeCamRebuild.markChunksOnDeactivate(camera);  // 重绘玩家区块喵
            camera = null;
        }
    }
}

// 移动：ClientTickEvent.Post 里调用喵
static void movementTick(Minecraft mc) {
    if (camera == null) return;
    Options o = mc.options;
    boolean sprint = o.keySprint.isDown();
    if (!o.keyUp.isDown() && !o.keyDown.isDown()) sprint = false;
    motion = decelerate(motion, 0.15, 0.4);         // 加速斜坡/减速因子喵
    double forward = sprint ? motion.x * 3 : motion.x;
    camera.handleMotion(forward, motion.y, motion.z);
}

private void handleMotion(double forward, double up, double strafe) {
    double yaw = Math.toRadians(getYRot());         // 沿朝向方向位移喵
    double scale = (0.07 * 10);                     // base*10，base 可配喵
    double x = (strafe * Math.cos(yaw) - forward * Math.sin(yaw)) * scale;
    double y = up * scale;
    double z = (forward * Math.cos(yaw) + strafe * Math.sin(yaw)) * scale;
    setDeltaMovement(new Vec3(x, y, z));
    move(MoverType.SELF, getDeltaMovement());       // 手动移动相机喵
}
```

// 相机转向：@Mixin(Entity.class) 拦截 turn，freecam 时重定向到相机喵
@Inject(method = "turn", at = @At("HEAD"), cancellable = true)
private void blockdustry$redirectTurn(double yawDelta, double pitchDelta, CallbackInfo ci) {
    if (!FreeCamManager.isActive() || !((Object) this instanceof LocalPlayer)) return;
    FreeCamCamera cam = FreeCamCamera.instance();
    if (cam != null && cam == Minecraft.getInstance().getCameraEntity()) {
        cam.setCameraRotations(cam.getYRot() + (float) yawDelta * 0.15F,
                Mth.clamp(cam.getXRot() + (float) pitchDelta * 0.15F, -90F, 90F));
    }
    ci.cancel();                                    // 玩家本体不转向喵
}

// 冻结玩家移动：@Mixin(LocalPlayer.class) 换假输入喵
@Inject(method = "tick", at = @At("HEAD"))
private void blockdustry$freezeInputPre(CallbackInfo ci) {
    if (FreeCamManager.isActive() && !config.playerMovement) {
        realInput = this.input; this.input = FreeCamInput.INSTANCE;  // 换成空操作输入喵
    }
}
@Inject(method = "tick", at = @At("RETURN"))
private void blockdustry$freezeInputPost(CallbackInfo ci) {
    if (realInput != null) { this.input = realInput; realInput = null; }
}

// 区块重建：相机跨区块时标脏（服务端不会为相机发新区块，必须本地重建）喵
static void markChunksForRebuild(int cx, int cz, int lastCx, int lastCz) {
    int vd = mc.options.renderDistance().get();
    // 新出现的边缘区块列全部 setSectionDirty，见 tweakeroo CameraUtils#markChunksForRebuild 喵
    for (int x = Math.min(lastCx, cx) + vd; x <= Math.max(lastCx, cx) - vd; ++x)
        for (int z = cz - vd; z <= cz + vd; ++z)
            if (mc.level.getChunkSource().getChunk(x, z, ChunkStatus.FULL, false) != null)
                mc.levelRenderer.setSectionDirty(x, 0, z, 16);   // 1.21.1 方法签名喵
}

## 四、冲突与风险清单喵

1. **鼠标捕获/视角锁**：freecam 必须抢走鼠标转向（拦截 `Entity.turn()`）。若玩家同时按住视角锁/瞄准辅助类功能会互相覆盖；建议 freecam 激活时强制取消玩家转向并独占鼠标增量喵。
2. **Jade 准星 tooltip**：freecam 射线拾取默认从相机实体（非玩家）发射，Jade tooltip 会跟随相机指向。若想保持玩家视角，需像 tweakeroo 一样在 `Minecraft.pick()` 里用真实玩家射线（见 `MixinMinecraft_freeCam`）喵。本工程已有 Jade 联动（`com.blockdustry.jade`），只显示血量 tooltip，freecam 下会照常跟随相机指向，属预期行为喵。
3. **区块加载**：相机飞离玩家后，新区块不会被服务器推送，不标脏重建会「看穿地形」；玩家本体区块也不会自动更新，必须实现 `markChunksForRebuild` 与退出时恢复喵。
4. **玩家离太远**：相机离玩家太远（超过服务端看门狗/同步距离）时，玩家实体仍被客户端持有，但服务器可能判定卡住/掉线？——纯客户端不发送移动包，通常安全；但相机超远时建议提示或自动关闭喵。
5. **死亡/重生**：玩家死亡重生时 `mc.player` 实例会替换，freecam 中需在 tick 里重新校验 `mc.player != originalCamera` 并修正引用（tweakeroo 注释里明确提到该坑）喵。
6. **Sodium/Iris**：tweakeroo 有专门针对 Sodium 的渲染冲突分支；本工程暂无 Sodium 依赖，但发布给玩家时需注意（备好 conditional-mixin 或兼容处理）喵。
7. **隐藏 UI**：默认隐藏手部/热键栏/状态条需多个 mixin；若只做最小版可先只保留快捷栏（`Gui.getCameraPlayer()` 返回真实玩家）喵。
8. **`smartCull`**：关闭后实体逐帧全量渲染，性能略降；freecam 关闭必须恢复喵。
9. **假输入的类型**：1.21.1 中 `LocalPlayer.input` 是 `ClientInput`，`KeyboardInput` 是其子类；`DummyMovementInput extends KeyboardInput` 覆写 `tick()` 为空即可（tweakeroo 同法）喵。

## 五、迁移工作量评估喵

- **最小可用版**：`FreeCamCamera` + 移动 + `Entity.turn` mixin + `LocalPlayer` 冻结 + `setCameraEntity` + 区块重建 ≈ 6 个新文件、3 个 mixin 条目，纯客户端喵。
- **完整版**：再加隐藏手部/HUD/经验条、预设存档、飞鼠滚轮调速、Jade 拾取覆盖 ≈ 12 个文件喵。
- 主要不确定点在 1.21.1 的 `LevelRenderer` 内部注入点（与参考工程 1.21.5 的 `LevelExtractor` 不同），实现时需对照本工程反编译源码核对方法签名喵。
