## 备注区（迁移特别小心点，基于真实源码）喵

### 数据订正（任务给的 size 有误，以源码为准）

- `thorium-reactor` 实际 **size 3**（不是 4×4），Blocks.java:2622

### 电力类
- **thorium-reactor（钍反应堆）**：NuclearReactor，核心坑是无冷冻液时 `heat` 持续上升（`heat += fullness*heating`），**heat≥0.999 → kill() + 爆炸（radius 19、damage 1250*4）**，shouldExplode 还要求 `items>=5 || heat>=0.5`。爆炸判定与 HeatBlock 热量输出（heatOutput=15）要一起迁。渲染有 `-top`（液体色）+ `-lights`（过热红黄闪烁）+ reactorsmoke 冒烟 + 紫光（lightColor 7f19ea lerp scarlet by heat）。Blocks.java:2618
- **impact-reactor（冲击反应堆）**：ImpactReactor **自耗电 25f 启动**（`consumePower(25f)`），warmup 幂 5 次方衰减，`efficiency>=0.9999 && power.status>=0.99` 才升温，未达阈值不产电且不能爆炸（explosionMinWarmup 0.3f）。draw 是 `DrawMulti(-bottom, DrawPlasma, DrawDefault)`——DrawPlasma 是等离子体动画，3D 迁移时要做动态贴图。Blocks.java:2632
- **thermal-generator（热能发电机）**：不是吃液体，是 `canPlaceOn` 校验地板 heat attribute（岩浆地板）> minEfficiency，产电 = `sum + attribute.env()`。放置 UI 要显示效率百分比。浮空（floating=true）。Blocks.java:2535
- **steam-generator / differential-generator**：ConsumeGenerator + consumeLiquid，**蒸汽机吃水 0.1f、温差机吃冷冻液 0.1f + 高温物品**，没液体系统前没法跑。蒸汽机的双 `-turbine` 反向旋转（rotateSpeed ±2、rotation 45°）是特色动画。Blocks.java:2546 / 2577
- **diode（二极管）**：PowerDiode 每帧把「后方电网 → 前方电网」电池电量差一半转移过去，只能单向（后方占比高于前方才传），有前后 bar。箭头贴图 `-arrow` 随 rotate 旋转。Blocks.java:2502
- **battery-large**：consumePowerBuffered(50000f)，baseExplosiveness 5f——被摧毁会炸，爆炸性比 battery 高 5 倍。Blocks.java:2512
- **solar-panel**：产电依赖 `Attribute.light.env() + (rules.lighting ? 1-ambientLight.a : 1)` × solarMultiplier，白天/夜间有差异。flags 被清空（攻击 AI 会优先打别的发电机）。Blocks.java:2607

### 墙体类
- **塑钢墙（plastanium-wall 系列）**：`insulated=true`（不导电，隔断电力网络）+ `absorbLasers=true`（吸收激光，挡住 lancer/meltdown 光束），这两个布尔属性要落进 Block 实体。Blocks.java:1729
- **合金墙（surge-wall 系列）**：`lightningChance=0.05`，受击有 5% 概率向入射反方向放电（Lightning.create，damage 20、len 17）。Blocks.java:1772
- **相织布墙（phase-wall 系列）**：`chanceDeflect=10f` 按 `10f/bullet.damage` 概率反弹子弹（把弹速反向 + 换 owner/team），`flashHit=true` 受击白闪（additive blend，Draw 里 hit 值衰减）。**drawDynamic 依赖 flashHit**。Blocks.java:1757
- **废墙（scrap-wall 系列）**：variants 5/4/3 随机贴图变体；buildCostMultiplier=4f（比普通墙 6f 低）。scrap-wall-gigantic 是 **size 4**。Blocks.java:1798
- **门（door 系列）**：Door 是 `solid=false, solidifes=true`，**连锁逻辑**——同队相邻门会 chained 成一组同开同关；`updateChained()` 在 proximity 变化时重建；开关时 `pathfinder.updateTile()` 刷新寻路；有实体在门格子上时不能关（`Units.anyEntities(tile) && !open` 跳过）。config 是 Boolean(open)。`-open` 开态贴图。Blocks.java:1785

### 防御类
- **force-projector（力墙投影）**：六边形护盾（sides=6，rotation 缓慢转），`bullet.absorb()` 吸收子弹 + buildup 累积，超载 break；`phaseRadiusBoost=80`（相位丝绸加半径）、相位还加盾量；**默认吃冷却液**（consumeCoolant=true，cooldownLiquid 更快回盾）。吸弹判定 `Intersector.isInRegularPolygon`。Blocks.java:1964
- **mend-projector / mender**：周期性释放治愈波（reload 秒一次，healPercent% 血量），`consumeItem(silicon/phaseFabric).boost()` 相位丝绸提升范围（phaseRangeBoost）与治疗量。有 `-top` 光效。Blocks.java:1919 / 1932
- **overdrive-projector / overdrive-dome**：给 range 内 `canOverdrive` 的建筑/单位加攻速移速（speedBoost 1.5/2.5），相位丝绸再 boost。放置时划线显示加成范围。Blocks.java:1944 / 1952
- **repair-turret（维修塔）**：RepairTurret 是**可旋转炮塔式**（有 rotation，激光随角度），`acceptCoolant=true` 吃冷却液加速维修；光束用 laser-white/laser-top 贴图 + pulse 脉冲圈。repair-point 是固定式（size1 无旋转头）。Blocks.java:6387 / 6397
- **shock-mine（脉冲地雷）**：ShockMine `update=false, targetable=false, solid=false, hasShadow=false`——**隐形的**，只有 `-team-top` 半透明队伍色罩可见；敌方单位 `unitOn` 踩上触发 tendrils 条闪电（damage 25，tileDamage 7f 扣自身）。Blocks.java:1978

### 炮塔类
- **meltdown（熔毁）**：LaserTurret 持续激光——`shootDuration=230f`（一次蓄力射 230 帧），`loopSound=beamMeltdown` 循环音，reload 靠冷却液消耗回充（**没冷却液 reload 不走**，LaserTurret.updateTile 里 reload 只靠 liquid.heatCapacity 减）。consumePower(17f) 高耗电。size 4。Blocks.java:4315
- **foreshadow（厄兆）**：**range=500f 全图级别**，RailBulletType 轨道炮（instShoot/instTrail 特效，damage 1350，穿透全屏），`maxAmmo=40` 但 **ammoPerShot=5**（打一炮吃 5 发弹药）；`cooldownTime=reload` 射击后长时间冷却；rotateSpeed 2f 转得慢；unitSort 优先打最强单位。size 4。Blocks.java:4203
- **lancer（蓝瑟）**：PowerTurret + `shoot.firstShotDelay=40f` 蓄力，蓄力音 chargeLancer + 蓄力光束特效（Fx.lancerLaserCharge），heatColor=red（过热红）。LaserBulletType 长度 173、pierceCap 4、buildingDamageMultiplier 0.25（打建筑弱）。Blocks.java:3561
- **segment（裂解）**：PointDefenseTurret 拦截敌方**子弹**（`Groups.bullet.intersect` 找目标，`bullet.type().hittable`），每发 pointBeam 打掉一发子弹，bulletDamage 30。consumePower(8f)。Blocks.java:3836
- **parallax（差扰）**：TractorBeamTurret 牵引光束，`force=16 + (1-dst/range)*scaledForce` 把敌人往自己拉，damage 0.5f/s 刮痧。激光用 laser/laser-start/laser-end 三贴图。Blocks.java:3641
- **hail/ripple（冰雹/浪涌）**：ArtilleryBulletType **抛物线弹道**（collidesTiles=false、minRange 限制最近射程——ripple minRange 50f、hail limitRange(0f)），hail reload 60f、ripple reload 120f 4 连发。弹道实体要能落地爆炸（splashDamage）。
- **cyclone（气旋）**：防空 FlakBulletType（collidesGround=true，只能打地面单位？不，Flak 是防空/反步兵），3 根独立后座炮管（recoils=3、`-barrel-1/2/3` 部件 under），高射速 reload 10f。Blocks.java:4085
- **spectre（幽灵）**：size 4 双管（ShootAlternate(8f) 交替），reload 7f 超高射速，consumeCoolant(1f) 冷却液消耗大。Blocks.java:4248
- **swarmer（蜂群）**：MissileBulletType **制导导弹**（homingPower），3 管×4 发（ShootBarrel barrels），reload 60*4/7。Blocks.java:3656
- **salvo（齐射）**：`consumeAmmoOnce=false`（一次扣 4 发弹药）、shoot.shots=4 齐射，DrawTurret `-side` 部件带 mirror（左右对称后座动画）。Blocks.java:3731
- **wave/tsunami（波浪/海啸）**：LiquidTurret 吃液体当弹药（liquidCapacity 10/40），带 **BlockFlag.extinguisher（灭火 flag）**——AI 会拿它喷火。tsunami 是 4 管（ShootAlternate(4f)）×2 发。Blocks.java:3529 / 3850
- **scorch（火焰）**：火焰弹 `collidesAir=false, hittable=false, pierce=true`（打不到空中、穿透地面敌人），reload 6f 高射速，shootCone 50f 散射大。Blocks.java:3419
