1. **旧游戏会话/旧构建**：三处修复均为 2026-08-13 当天 ~14:42-14:44 完成；`runClient` 直接加载 `build/classes` + `build/resources`，若游戏在修复前启动未重启，看到的自然是旧行为喵。重跑 `./gradlew runClient`（全新会话）即可看到修复喵。
