## 二、主会话挂载点（按序合并，全部必须）喵

### 1. register — `Blockdustry.java` 构造器
在 `ElevatorBlocks.register(modEventBus);` 之后加一行：
```java
com.blockdustry.distribution.SorterRegistrar.register(modEventBus);
```
（`SorterNetwork` 是 @EventBusSubscriber 自动发现，无需显式注册喵）

### 2. tab — `BlockdustryBlocks.java` DISTRIBUTION_TAB
在 `output.accept(ElevatorBlocks.ELEVATOR_ITEM);` 之后加两行：
```java
output.accept(com.blockdustry.distribution.SorterRegistrar.SORTER_ITEM);
output.accept(com.blockdustry.distribution.SorterRegistrar.INVERTED_SORTER_ITEM);
```

### 3. ResearchNodes — `ResearchNodes.java` all()，在 router 节点后加 2 节点
```java
ResearchNode.builder("sorter")
        .parent("router")
        .unlockBlock(com.blockdustry.distribution.SorterRegistrar.SORTER.get())
        .buildRequirement(lead, 2)      // Mindustry sorter = 铅×2 铜×2 喵
        .buildRequirement(copper, 2)
        .build(),
ResearchNode.builder("inverted_sorter")
        .parent("sorter")
        .unlockBlock(com.blockdustry.distribution.SorterRegistrar.INVERTED_SORTER.get())
        .buildRequirement(lead, 2)      // Mindustry inverted-sorter = 铅×2 铜×2 喵
        .buildRequirement(copper, 2)
        .build(),
```
（`lead`/`copper` 用 all() 顶部已有的局部变量：lead=BlockdustryBlocks.LEAD.get()、copper=Items.COPPER_INGOT 喵）

### 4. 渲染 — `BlockdustryClient.java` registerRenderers
在提升机渲染器行之后加一行：
```java
event.registerBlockEntityRenderer(com.blockdustry.distribution.SorterRegistrar.SORTER_ENTITY.get(), com.blockdustry.client.SorterBlockEntityRenderer::new);
```
（SORTER_ENTITY 同时覆盖 sorter 与 inverted_sorter 两方块喵）

## 三、行为要点（验收对照）喵
- **sorter**：设定某物品 → 该物品沿来向直通（对侧输出）；其他物品两侧输出喵
- **invertedSorter**：设定物品两侧输出；其他物品直通喵
- 未设定：sorter 全侧出、invertedSorter 全直通（Mindustry configClear 语义）喵
- 瞬时传递（无缓冲）：acceptItem 即校验目标邻居可收，handleItem 立即移交喵
- 防 3 连环/侧向死循环：源+目标双 sorter 时拒收；双侧都收时按 bit 轮换喵
- 菜单：空手右键 → SorterScreen（列 allMaterials，当前 ✓，清除按钮）喵
