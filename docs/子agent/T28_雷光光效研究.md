# T28 雷光（fuse）光效/视觉深度研究移植设计喵

> 任务：只研究、不改任何 Blockdustry 代码喵。深挖 Mindustry 原版 fuse（雷光）炮的全部光效与视觉实现，与现有 Blockdustry 实现逐条对照，产出可落地的移植设计喵。
> 数据不串：fuse = `Blocks.java:3915` 的 `new ItemTurret("fuse")`，发射 ShrapnelBulletType 金属碎片霰弹，**不是火焰**喵。绝未套用 duo/scatter/arc 的任何参数喵。
> 结论先行：**原版 fuse 弹是「金属碎片」不是火焰，现有 FireBulletRenderer 双层火球 + FLAME 粒子是完全错误的视觉，必须重做**喵。

## 一、fuse 原版完整定义喵

### 1. Blocks.java L3915-3953（fuse 本体）喵

```java
fuse = new ItemTurret("fuse"){{
    requirements(Category.turret, with(Items.copper, 225, Items.graphite, 225, Items.thorium, 100));

    reload = 35f;          // 装填 35 tick
    shake = 4f;            // 每发屏幕震动 4
    range = 90f;           // 射程 90 单位 = 11.25 格
    recoil = 5f;           // 视觉后坐 5 单位 = 0.625 格

    shoot = new ShootSpread(3, 20f);   // 扇形 3 发、弹间 20°

    shootCone = 30;        // 瞄准锥 30°
    size = 3;              // 3×3 占地
    envEnabled |= Env.space;

    scaledHealth = 220;
    shootSound = Sounds.shootFuse;     // 声音资源 sounds/shoot/shootFuse.ogg
    shootSoundVolume = 0.9f;
    coolant = consumeCoolant(0.3f);    // 需水冷（本 mod 未建模，不属光效）

    float brange = range + 10f;        // = 100 单位 = 12.5 格

    ammo(
        Items.titanium, new ShrapnelBulletType(){{
            length = brange;           // 100
            damage = 66f;
            ammoMultiplier = 4f;
            width = 17f;               // 弹片宽度 17 单位
            reloadMultiplier = 1.3f;
        }},
        Items.thorium, new ShrapnelBulletType(){{
            length = brange;           // 100
            damage = 105f;
            ammoMultiplier = 5f;
            toColor = Pal.thoriumPink;            // 终点色 f9a3c7
            shootEffect = smokeEffect = Fx.thoriumShoot;  // 炮口闪光覆盖为粉色版
        }}
    );
    depositCooldown = 1.0f;
}};
```

关键事实喵：
- fuse **没有**设置 `emitLight` / `lightRadius` / `lightColor` / `lightOpacity`，因此**方块本体不发光**喵。
- fuse **没有**在 turret 级设置 `shootEffect`/`smokeEffect` 覆盖（为 null），所以实际炮口特效取**弹药自带**的 `type.shootEffect`/`type.smokeEffect` 喵。
- 弹药两种：titanium（默认颜色，白→`Pal.lancerLaser` a9d8ff）与 thorium（白→`Pal.thoriumPink` f9a3c7，炮口特效换成 `Fx.thoriumShoot`）喵。当前 Blockdustry 只启用 titanium 喵。
- 开火弹道为 **ShootSpread(3, 20f)**：3 发同时出膛，角度偏移 `i*20 - (3-1)*20/2` = **-20°/0°/+20°**，无 firstShotDelay（同时打）喵。

## 二、开火特效逐条（Fx 名称 + 完整参数 + 触发阶段）喵

开火流程在 `Turret.TurretBuild.bullet()`（Turret.java L778-818）。每发弹丸出膛时依次触发喵：

### 1. 炮口闪光（muzzle flash）喵
```java
// Turret.java L794
(shootEffect == null ? type.shootEffect : shootEffect).at(bulletX, bulletY, rotation + angleOffset, type.hitColor);
// Turret.java L795
(smokeEffect == null ? type.smokeEffect : smokeEffect).at(bulletX, bulletY, rotation + angleOffset, type.hitColor);
```
- fuse 的 `shootEffect`/`smokeEffect` 都未在 turret 级设置（null），所以都取弹药的：`type.shootEffect == type.smokeEffect` 喵。
- **titanium 弹药**：两者都是 `Fx.lightningShoot` → 炮口**同时叠两个** `Fx.lightningShoot` 实例（一个算 shoot、一个算 smoke）喵。
- **thorium 弹药**：两者都是 `Fx.thoriumShoot`（同上叠两个）喵。
- 位置 = 炮口 `(bulletX, bulletY)`；`bulletX = x + Angles.trnsx(rotation-90, shootX, shootY)`，`shootX=0`、`shootY=12`（init 时 `shootY = size*tilesize/2 = 12`，Turret.java L206）喵。
- 传入颜色 `type.hitColor`（ShrapnelBulletType 未覆盖 = `Color.white`）喵。

### 2. `Fx.lightningShoot` 完整定义（Fx.java L2408）喵
```java
lightningShoot = new Effect(12f, e -> {
    color(Color.white, Pal.lancerLaser, e.fin());   // 白 → 浅蓝 a9d8ff 渐变（随 e.fin()）
    stroke(e.fout() * 1.2f + 0.5f);                 // 线宽：fout 从 1.7 衰减到 0.5
    randLenVectors(e.id, 7, 25f * e.finpow(), e.rotation, 50f, (x, y) -> {
        lineAngle(e.x + x, e.y + y, Mathf.angle(x, y), e.fin() * 5f + 2f);  // 每根线长 2→7
    });
});
```
- `randLenVectors` = `arc.math.Angles.randLenVectors`：用 `e.id` 播种生成 7 个点，角度在 `e.rotation ± 50°` 内随机、长度 0~`25*finpow` 随机喵。
- 视觉：**7 根白色→浅蓝的短辐射短线**，在炮口 ±50° 锥内向外爆开，lifetime 12 tick（约 0.2 秒），随 fout 变细变淡喵。
- `finpow() = fin²`（开头最密，随后扩散）；`fin = time/lifetime`、`fout = 1-fin`、`fslope = sin(fin·π)`（弧线库 Scaled 接口，0→1→0 钟形）喵。

### 3. `Fx.thoriumShoot` 完整定义（Fx.java L2417，thorium 弹药专用）喵
```java
thoriumShoot = new Effect(12f, e -> {
    color(Color.white, Pal.thoriumPink, e.fin());   // 白 → 粉 f9a3c7 渐变

    });
});
```
- 与 lightningShoot 唯一区别：渐变终点色是 `Pal.thoriumPink = f9a3c7` 喵。

### 4. 声音喵
```java
// Turret.java L796
(type.shootSound != Sounds.none ? type.shootSound : shootSound).at(bulletX, bulletY, Mathf.random(soundPitchMin, soundPitchMax), shootSoundVolume);
```
- ShrapnelBulletType 的 `shootSound = Sounds.none`，故用炮塔 `Sounds.shootFuse`，音量 0.9，音高随机 [0.9, 1.1] 喵。
- 声音资源 `core/assets/sounds/shoot/shootFuse.ogg`（原版唯一 fuse 专属音频）喵。

### 5. 抛壳 / 弹药消耗特效喵
```java
// Turret.java L798
ammoUseEffect.at(x - Angles.trnsx(rotation, ammoEjectBack), y - Angles.trnsy(rotation, ammoEjectBack), rotation * Mathf.sign(xOffset));
```
- fuse 未设置 `ammoUseEffect`，默认 `Fx.none` → **原版无抛壳特效**喵。

### 6. 屏幕震动 + 后坐 + 热区喵
```java
// Turret.java L804
if(shake > 0){ Effect.shake(shake, shake, this); }   // fuse shake=4
// Turret.java L808
curRecoil = 1f;                                       // 整体后坐归 1
// Turret.java L812
heat = 1f;                                            // 热区归 1
```
- 后坐动画：`recoilOffset.trns(rotation, -Mathf.pow(curRecoil, recoilPow) * recoil)`（Turret.java L532），`recoilPow=1.8`、`recoil=5`，每 tick 以 `1/recoilTime` 衰减，`recoilTime=reload=35`（Turret.java L208）喵。
- 热区：`heat` 以 `1/cooldownTime` 衰减，`cooldownTime=20`（默认）；`DrawTurret.drawHeat`（DrawTurret.java L137-141）用 `Drawf.additive(heat, block.heatColor.a(heat), x+recoilOffset.x, y+recoilOffset.y, drawrot(), heatLayer)`，`heatColor = Pal.turretHeat = ab3400`（暗橙红），贴图 `fuse-heat.png`（96×96，与原 fuse.png 同尺寸）喵。
- **原版 fuse 开火无任何 Drawf.light 点光/线光在炮塔侧**，光效全部来自子弹喵。

### 7. 命中特效喵
- 碎片是 hitscan（`speed=0`），在 `init()` 时经 `Damage.collideLaser` 一次性结算激光碰撞喵。
- `Damage.collideLine`（Damage.java L256-331）对每个命中点：单位走 `hitter.collision(u, x, y)` → `type.hit()` → `hitEffect.at(...)`；建筑走 `hitter.type.hit(hitter, x, y)` → 同样 `hitEffect`喵。
- ShrapnelBulletType 的 `hitEffect = Fx.hitLancer`（默认 `Fx.hitLancer`，L23）→ **每个命中点爆一次白闪**喵。
- `Fx.hitLancer`（Fx.java L992）：
```java
hitLancer = new Effect(12, e -> {
    color(Color.white);                  // 纯白
    stroke(e.fout() * 1.5f);             // 线宽 1.5→0
    randLenVectors(e.id, 8, e.finpow() * 17f, (x, y) -> {
        float ang = Mathf.angle(x, y);
        lineAngle(e.x + x, e.y + y, ang, e.fout() * 4 + 1f);  // 每根线长 1→5
    });
});
```
- 视觉：**8 根白色辐射短线**（lifetime 12），全方向爆开，命中点白闪喵。
- 子弹自然到期 `despawnEffect = Fx.none` → **消失时无特效**喵。

## 三、弹丸（ShrapnelBulletType）渲染逐条喵

### 1. 构造函数（ShrapnelBulletType.java L21-33）喵
```java
public ShrapnelBulletType(){
    speed = 0f;                 // 不动：hitscan，瞬间命中
    hitEffect = Fx.hitLancer;
    shootEffect = smokeEffect = Fx.lightningShoot;
    lifetime = 10f;             // 存活 10 tick 后消失
    despawnEffect = Fx.none;
    keepVelocity = false;
    collides = false;
    pierce = true;              // 穿单位
    hittable = false;           // 不可被拦截
    absorbable = false;
    lightOpacity = 0.6f;        // 光透明度 0.6
}
```
- **speed=0 + lifetime=10**：弹丸停在炮口不动，仅作为一条「会淡出的长条」存活 10 tick，这就是原版 fuse 的「瞬击闪存」观感喵。
- `init(Bullet b)` 里 `Damage.collideLaser(b, length, hitLarge, laserAbsorb, pierceCap)` 一次性结算，命中长度写进 `b.fdata`（Damage.java L222-230）喵。

### 2. `draw()` 完整源码（ShrapnelBulletType.java L55-70）——逐字关键喵
```java
@Override
public void draw(Bullet b){
    float realLength = b.fdata, rot = b.rotation();   // realLength = 实际命中长度（≤length=100）

    Draw.color(fromColor, toColor, b.fin());          // 颜色：fromColor(白) → toColor 随 e.fin() 渐变
    for(int i = 0; i < (int)(serrations * realLength / length); i++){
        Tmp.v1.trns(rot, i * serrationSpacing);        // 沿飞行方向每 8 单位一个
        float sl = Mathf.clamp(b.fout() - serrationFadeOffset) * (serrationSpaceOffset - i * serrationLenScl);
        Drawf.tri(b.x + Tmp.v1.x, b.y + Tmp.v1.y, serrationWidth, sl, b.rotation() + 90);  // 锯齿棘（垂直）
        Drawf.tri(b.x + Tmp.v1.x, b.y + Tmp.v1.y, serrationWidth, sl, b.rotation() - 90);  // 左右各一根
    }
    Drawf.tri(b.x, b.y, width * b.fout(), (realLength + 4f), b.rotation());   // 主体长条
    Drawf.tri(b.x, b.y, width * b.fout(), 10f, b.rotation() + 180f);          // 尾部钝角小三角
    Draw.reset();

    Drawf.light(b.x, b.y, b.x + Angles.trnsx(rot, realLength), b.y + Angles.trnsy(rot, realLength), width * 2.5f * b.fout(), toColor, lightOpacity);
}
```
- 字段默认值（L13-19）：`length=100`、`width=20`、`fromColor=Color.white`、`toColor=Pal.lancerLaser`、`serrations=7`、`serrationLenScl=10`、`serrationWidth=4`、`serrationSpacing=8`、`serrationSpaceOffset=80`、`serrationFadeOffset=0.5` 喵。
- fuse 的 titanium 覆盖 `width=17`；thorium 额外覆盖 `toColor=Pal.thoriumPink` 喵。

### 3. 形状：一条「沿飞行方向拉伸的长三角」喵
- `Drawf.tri(x, y, width, length, rotation)`（Drawf.java L543-554）画**等腰三角形**：底边在 `(x,y)`、宽 `width`；顶点在 `rotation` 方向前方 `length` 处喵。
```java
public static void tri(float x, float y, float width, float length, float rotation){
    float fx = Angles.trnsx(rotation, length), fy = Angles.trnsy(rotation, length);
    float rx = Angles.trnsx(rotation - 90f, width / 2f), ry = Angles.trnsy(rotation - 90f, width / 2f);
    Fill.tri(x + rx, y + ry, x + fx, y + fy, x - rx, y - ry);
}
```
- 主体：底宽 `width*fout`（=17 单位起，随 fout 缩到 0），长 `realLength+4`（≈100 单位），沿 `rotation` 伸出 → **炮口宽、远端尖的长锥形金属片**喵。
- 尾部：`width*fout` 宽、10 单位长、`rotation+180°` 反向小三角，补上「弹尾钝头」喵。
- 锯齿：沿长度每隔 8 单位（`serrationSpacing`）左右各一根垂直短三角（宽 4、长 `clamp(fout-0.5)*(80-i*10)`），仅当 `fout>0.5` 时可见，越靠前越短、随 fout 消失 → **弹体上的「金属倒刺」**喵。

### 4. 颜色与衰减喵
- `Draw.color(fromColor, toColor, b.fin())`：**颜色随生命周期 fin 从纯白渐变到终点色**（titanium→`a9d8ff` 浅蓝，thorium→`f9a3c7` 粉），不是沿弹体渐变喵。
- 透明度/宽度衰减全靠 `b.fout()`（1→0，10 tick）：主体宽度 `width*fout`、锯齿 `clamp(fout-0.5)`、整条随 fout 淡出喵。
- 无内建 alpha 字段：`Draw.color` 后直接画三角，随 fout 缩窄视觉上即淡出喵。

### 5. 拖尾（trail）：**原版无此实现**喵
- ShrapnelBulletType **没有设置** `trailLength` / `trailWidth` / `trailColor` / `trailEffect` 喵。
- BulletType 默认 `trailLength = -1`（≤0 禁用拖尾，BulletType.java L286）、`trailChance = -0.0001f`（负数禁用粒子尾迹，L271）、`trailEffect = Fx.missileTrail`、`trailColor = Pal.missileYellowBack`（e58956，但这只在 trailLength>0 时才用）喵。
- 且 ShrapnelBulletType **完全重写 draw() 且不调用 super.draw()**（不调 drawTrail/drawParts）→ **碎片弹绝无拖尾、无粒子、无附加部件**喵。
- **结论：原版 fuse 弹没有任何火焰/尾迹粒子，现有 FireBulletEntity 的 `ParticleTypes.FLAME` 拖尾是凭空加的**喵。

### 6. 光效（在 draw() 内直接调 Drawf.light 线光）喵
```java
Drawf.light(b.x, b.y, b.x + Angles.trnsx(rot, realLength), b.y + Angles.trnsy(rot, realLength), width * 2.5f * b.fout(), toColor, lightOpacity);
```
- 是 **线形光**（LightRenderer.line，见 T15）：从弹体起点到终点一路照亮，stroke = `width*2.5*fout`（titanium=42.5 起，随 fout 缩），颜色 `toColor`（浅蓝/粉），透明度 0.6 喵。
- 另有 BulletComp.draw() 尾随调 `type.drawLight(self())`（BulletComp.java L324）→ `BulletType.drawLight`（BulletType.java L695-698）打**点光**：`lightRadius` 默认 -1 → init 时 `max(18, hitSize*5) = max(18, 20) = 20` 单位，`lightColor = Pal.powerLight = fbd367`（暖黄），`lightOpacity=0.6` 喵。
- 即**每发碎片同时有一路线光（终点色）+ 一个暖黄点光（炮口）**喵。

## 四、光效（Light）调用点清单（原版 fuse 发光点）喵

按 T15 结论：Mindustry 光效 = 屏幕空间叠加（LightRenderer + Shaders.light），光源无生命周期字段、透明度由调用方每帧传喵。fuse 相关光源如下喵：

| # | 位置 | 调用 | 形态 | 颜色 | 透明度 | 生命周期 |
|---|---|---|---|---|---|---|
| 1 | 碎片弹主体（每发 3 条之一） | `ShrapnelBulletType.draw()` L69 | 线形光 `Drawf.light(x,y,x2,y2,stroke,tint,alpha)` | `toColor`（titanium a9d8ff / thorium f9a3c7） | 0.6 | 随 `b.fout()` 10 tick 淡出，stroke `width*2.5*fout` |
| 2 | 碎片弹起点（炮口） | `BulletType.drawLight()`（BulletComp.draw 尾调） | 点光 `Drawf.light(b, radius, color, opacity)` | `Pal.powerLight` fbd367 暖黄 | 0.6 | 同子弹 10 tick 淡出，radius 20 单位 |
| 3 | 炮塔本体 | 无 | 无 | — | — | fuse **未设** emitLight/lightRadius/lightColor → **不发光**喵 |
| 4 | 开火 | 无 Drawf.light | 无 | — | — | 炮口闪光/震动/热区全是 Effect（普通绘制 pass），**不影响光 buffer**喵 |

关键：**原版 fuse 的全部光源来自子弹（2 个/发 × 3 发 = 每轮 6 个光调用）**，炮塔本身与开火瞬间不发任何光喵。热区（fuse-heat）是 additive 普通绘制，不是光喵。

## 五、现有 Blockdustry 实现 vs 原版 差距对照表喵

## 六、移植设计：逐条对应「改哪个文件 / 怎么画 / 参数值」喵

### A. 弹丸渲染重做（核心）喵

**改 `FireBulletRenderer.java`**：把「双层火球」换成「沿速度方向的碎片长条」喵。

- **形状**：`RenderType.entityTranslucent`（或 entityCutout 无透明底）画**一块水平大 quad**，从弹丸位置向后延伸 `L = min(range, 命中长)` 格、宽从 `W` 线性缩到 0（锥形），即一个等腰三角的近似喵。参数：titanium `W=17/8=2.125` 格、`L=100/8=12.5` 格（可按弹速换算剩余）喵。
- **颜色**：`lerpColor(white, toColor, fin)`，`toColor` titanium=`a9d8ff` / thorium=`f9a3c7`；`fin = 1 - life/maxLife` 喵。**不要用 ffdd55/db401c 火焰色**喵。
- **衰减**：alpha 与宽都乘 `fout = 1-fin`；`life` 从 10 tick 递减 → 10 tick 内宽 2.125→0、整条淡出喵。
- **锯齿（可选，贴真）**：沿长条每 `8/8=1` 格画一根垂直小三角（宽 4/8=0.5 格、长 `clamp(fout-0.5)*(80-i*10)/8`），数量 `(int)(7*len/100)` 喵。
- **尾部钝角**：弹尾补一根反向短三角（长 10/8=1.25 格）喵。
- 顶点格式：全亮 `setLight(0xF000F0)` + `setOverlay(OverlayTexture.NO_OVERLAY)`（坑-炮管黑.md），y 抬高避免与地表共面，双面绘制用 entityTranslucent 喵。
- **贴图**：无需贴图（纯色染 quad 即可）；如需质感可拷 Mindustry 无 —— 原版碎片是纯色三角，**无贴图**，故用纯色 quad 最忠于原版喵。

### B. 弹丸逻辑与粒子（改 `FireBulletEntity.java`）喵

- **删除** `spawnFireTrail()` 与 `ParticleTypes.FLAME` 调用：原版无任何粒子拖尾喵。
- **行为**：保持飞行弹（bulletSpeed=1.8）即可，渲染随速度方向对齐；若想更贴近「瞬击」，可把寿命缩短并让渲染从炮口到命中点一次画满（见 D）喵。

## 七、结论（协调者要求明确写）喵

**原版 fuse 弹是碎片不是火焰**喵：
- 它画的是**一条沿飞行方向的白色→浅蓝（钍弹为粉）长三角金属片**，随 fout 在 10 tick 内缩窄淡出，带金属倒刺与尾部钝角，**没有任何火焰/火球/粒子拖尾**喵。
- 现有 `FireBulletRenderer` 的双层火球（lightFlame 亮黄 + darkFlame 深橙红）+ `FireBulletEntity` 的 `ParticleTypes.FLAME` 拖尾，**把原版的金属碎片霰弹视觉错画成了火系弹**，颜色/形状/粒子三者全错，必须重做喵。
- 应改成：**沿速度方向的长三角纯色 quad**（白→a9d8ff、宽 2.125→0、fout 淡出 10 tick）+ **删掉 FLAME 粒子** + 补 **muzzle flash（Fx.lightningShoot 白→蓝辐射线）** 与 **命中白闪（Fx.hitLancer）**；光效补 **toColor 线光 + 暖黄点光**；转盘补 **fuse_heat 热区**与**正确的 5 单位后坐**喵。
