# ^T22 材料调整（赛普罗限定 / 原版煤炭铜覆盖 / 物品源菜单）喵

> 在 T20 材料迁移基础上的用户新要求调整喵。
> 相关：`^T20_材料迁移与物品源.md`（基底）、`docs/坑/贴图.md`（命名）、`docs/坑/物流交接.md`（dumpItem）喵。

## 1. 只做赛普罗（Serpulo），删除埃里克尔（Erekir）6 材料 喵

- 删除注册：`BlockdustryItems.java` 移除 `BERYLLIUM/TUNGSTEN/OXIDE/CARBIDE/FISSILE_MATTER/DORMANT_CYST` 6 个 `DeferredItem`，`newMaterials()` 收窄为 11 个赛普罗材料（copper/metaglass/titanium/thorium/plastanium/phase_fabric/surge_alloy/spore_pod/blast_compound/pyratite/scrap）喵。
- 删除文件：6 张贴图 `textures/item/{name}.png` + 6 个模型 `models/item/{name}.json` 已删除喵。
- 删除 lang：zh_cn/en_us 各移除 6 条 `item.blockdustry.{name}` 喵。
- 删除创造栏：`BlockdustryBlocks.ITEMS_TAB` 移除 6 个 `output.accept(BlockdustryItems.XXX)` 喵。
- `allMaterials()`（16 个）= MC 煤 + MC 沙 + 石墨/硅/铅 + 11 个新材料，物品源菜单 / 核心白名单随之自动收窄喵。

## 2. 核心白名单同步 喵

- `CoreBlockEntity.WHITELIST` 由 `BlockdustryItems.allMaterials()` 惰性缓存构建，删除埃里克尔材料后自动只含赛普罗材料，无需额外改动喵。

## 3. 覆盖原版「煤炭」「铜」视觉（模型 + 贴图）喵

- 方案：**mod 资源作为资源包层覆盖 `minecraft` 命名空间物品模型**（NeoForge mod 资源包优先级高于原版，可覆盖 `assets/minecraft/models/item/{name}.json`）喵。
- 新建 `assets/minecraft/models/item/coal.json`：`layer0 = blockdustry:item/coal`（Mindustry 煤贴图，复制自 `item-coal.png`）喵。
- 新建 `assets/minecraft/models/item/copper_ingot.json`、`raw_copper.json`：`layer0 = blockdustry:item/copper`（Mindustry 铜贴图）喵。
- 效果：矿洞掉落/物品栏的原版煤炭、铜锭、粗铜显示 Mindustry 视觉；物品源产的煤（Items.COAL）同样生效喵。
- 备注：若未来不想覆盖原版，可移除这三个 `assets/minecraft/...` 文件即可回退喵。

## 4. 物品源改菜单式切换（Mindustry 配置菜单风格）喵

- `ItemSourceBlock.useWithoutItem`：客户端空手右键 `mc.setScreen(new ItemSourceScreen(pos, current))`，服务端仅 `CONSUME`（不再右键循环）喵。
- 新建 `client/ItemSourceScreen.java`：两列网格按钮列出 `BlockdustryItems.allMaterials()`（16 个赛普罗材料），当前产物标「✓」；点按钮 `PacketDistributor.sendToServer(ItemSourceSelectPayload)` 喵。
- 新建 `network/ItemSourceSelectPayload.java`：`(BlockPos pos, String itemId)`，客户端→服务端喵。
- `BlockdustryNetwork`：注册 `playToServer` + `handleItemSourceSelect`，服务端解析物品并校验在 `allMaterials()` 内后 `src.setProduct(item)`，非法物品忽略喵。
- `ItemSourceBlockEntity`：`cycleProduct()` 删除，改 `setProduct(Item)`（校验 + sendBlockUpdated 同步客户端）喵。

## 5. 编译验证 喵

- `./gradlew compileJava` **BUILD SUCCESSFUL**（仅存既有 `@EventBusSubscriber bus()` 过时警告，与本次无关）喵。

## 6. 后续未做 / 备注 喵

- 菜单为简易无滚动两列布局（16 项 ≈ 8 行，标准 GUI 高度内可容纳）喵。
- 覆盖原版模型依赖 mod 资源包层；专用服不加载模型资源，无副作用喵。
- 材料仍未接入配方/机器消耗（石墨压缩机吃煤、单位工厂吃硅+铅），后续可引用 `BlockdustryItems.allMaterials()` 喵。
