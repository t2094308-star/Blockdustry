# T13 灵魂出窍（Freecam）应用 阶段产出喵

## 目标喵
按 T3 方案在 Blockdustry（NeoForge 1.21.1，Mojang 映射）落地「灵魂出窍」freecam 最小可用版：伪造 `LocalPlayer` 相机实体塞进 `setCameraEntity()`，玩家身体原地冻结，WASD/疾跑/跳跃驱动相机飞行，鼠标转向重定向到相机；与炮台附身互斥喵。

## 一、实现概览喵
采用 T3 推荐的「相机实体」方案（tweakeroo 移植），概念 1:1 迁到 1.21.1 签名喵：
- **相机实体** `FreecamEntity extends LocalPlayer`：`noPhysics=true`、`isSpectator()` 恒真、`getId()` 复用原相机实体 id；创建/移除时读写 `Minecraft.setCameraEntity()` 与 `mc.smartCull` 喵。
- **身体冻结**：`LocalPlayer` mixin 在 `tick()` HEAD/RETURN 把 `input` 换成空操作 `FreecamInput`，并强制 `isControlledCamera()` 恒真（避免 `serverAiStep` 沿用上一帧旧 `xxa/zza` 让身体漂移）、`swing()` 取消挥臂喵。
- **鼠标转向**：`Entity.turn()` HEAD 拦截，freecam 时把 `(dx,dy)*0.15` 叠加到相机朝向并 `ci.cancel()`，玩家本体不转向喵。
- **相机移动**：`ClientTickEvent.Post` 每 tick 调 `FreecamEntity.movementTick()`：按键读 `mc.options`，衰减算法算速度（加速斜坡 0.15、减速因子 0.4），`move(MoverType.SELF, ...)`（noPhysics 不碰撞），疾跑前进×3，速度 `0.07*10` 喵。
- **区块重建**：相机跨区块时 `LevelRenderer.setSectionDirty(cx, cy, cz)`（cy 0..15）标脏新出现的边缘区块；退出时重绘相机范围外的玩家区块喵。
- **身体可见**：✅ 无需额外 mixin——NeoForge 自带补丁把渲染条件改为 `(!(entity instanceof LocalPlayer) || cameraEntity == entity || (entity == mc.player && !mc.player.isSpectator()))`，freecam 相机实体≠玩家且玩家非观战时身体自动渲染喵。
- **交互屏蔽**：`InputEvent.InteractionKeyMappingTriggered` 取消攻击/使用 + `MultiPlayerGameMode` mixin 屏蔽 `startDestroyBlock/continueDestroyBlock/useItemOn/useItem/interact/interactAt/attack` 喵。
- **HUD/观感**：`Gui.getCameraPlayer()` 返回真实玩家（修快捷栏）；`GameRenderer.renderItemInHand()` 隐藏手臂；`Camera.getFluidInCamera()` 返回 NONE 去水雾；`MultiPlayerGameMode.hasExperience()` 返回 false 隐藏经验条喵。

## 四、快捷键喵
- **F4** 切换灵魂出窍（`InputConstants.Type.KEYSYM` + `KEY_F4`），category `key.categories.blockdustry`，lang 已加中英条目喵。
- 注册走 MOD 总线 `RegisterKeyMappingsEvent`（在 `BlockdustryClient`），读取走 GAME 总线 `ClientTickEvent.Post` 的 `KEY_FREECAM.consumeClick()` 喵。
- 如需改键，在 设置→按键→方块工业 里重绑即可喵。

## 五、与炮台附身互斥喵
`FreecamHandler` 内实现双向互斥：
1. **freecam 激活时退出附身**：`setActive(true)` 里若 `TurretPossessHandler.isPossessing()` 则 `PacketDistributor.sendToServer(new TurretPossessExitPayload(pos))`，并置 `pendingPossessionExit` 防服务端确认前的窗口期误关喵。
2. **附身激活时退出 freecam**：`ClientTickEvent.Post` 里若 `isPossessing() && !pendingPossessionExit` → `setActive(false)`；附身解除后清除标志喵。
3. **附带**：freecam 激活期间屏蔽攻击/使用键 → 无法右键炮塔进入附身，天然互斥喵。

## 六、风险喵
1. **玩家死亡重生**：`mc.player` 实例会替换，`FreecamHandler` 每 tick 用 `FreecamEntity.isOriginalPlayerStillValid()` 校验（`mc.player == originalCamera`），失效即关闭；退出时 `originalCameraWasPlayer ? mc.player : originalCamera` 兜底恢复相机喵。
2. **区块**：相机飞离玩家超过渲染距离后服务器不会推送新区块，会看到未加载地形（void）；`markChunksForRebuild` 只重建客户端已加载区块。如需超远飞行需服务端配合或加大视距，属已知限制喵。
3. **Sodium/Iris**：未依赖，未做条件兼容；若玩家装 Sodium，`setSectionDirty` 标脏路径可能需额外适配（参考 tweakeroo sodium_breaks 分支）喵。
4. **`isControlledCamera` 恒真**：会触发 `LocalPlayer.sendPosition()` 内位置包发送分支，但身体静态 + 转向被取消 → `flag2` 恒假，实际不发包；身体仍由服务端保持原位喵。
5. **NeoForge 补丁依赖**：身体渲染依赖 NeoForge 自带补丁（`entity == minecraft.player && !isSpectator()`），纯 vanilla 环境不生效；本工程为 NeoForge mod 无此问题喵。
6. **`renderLevel` 内 `getEntity()` ordinal 假设**：本版未使用 LevelRenderer mixin（身体渲染靠 NeoForge 补丁），故无 ordinal 脆弱性问题喵。
7. **GUI 打开时**：打开背包/设置等屏幕时鼠标转向暂停，freecam 相机静止；切回即恢复，未做额外处理喵。
