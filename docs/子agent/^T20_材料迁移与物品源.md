## 2. 贴图来源与命名 喵

- 全部贴图直接复制自 `D:\Blockdustry\Mindustry\core\assets-raw\sprites\items\item-{name}.png`，32×32 RGBA，与现有 graphite/silicon/lead 完全一致（已校验 md5 相同）喵。
- 复制到 `src/main/resources/assets/blockdustry/textures/item/{name}.png`，连字符 `-` 改下划线 `_`（phase_fabric / surge_alloy / spore_pod / blast_compound / fissile_matter / dormant_cyst）喵。
- 命名遵循贴图规范：物品贴图（无面编号），64×64 标准以下（32×32）无需标注「标准/高清」喵。

## 3. 注册清单 喵

### 新文件 `src/main/java/com/blockdustry/item/BlockdustryItems.java` 喵

- 独立 `DeferredRegister.Items ITEMS`（`blockdustry` modid），17 个 `DeferredItem<Item>` 全为普通 `new Item(...)`，避免动共享 `BlockdustryBlocks.ITEMS` 喵。
- 提供运行时方法（避免注册期 `get()` 未绑定/静态循环初始化）：
  - `newMaterials()`：本类 11 个新材料列表喵。
  - `allMaterials()`：全部迁移材料 = MC 煤 + MC 沙 + 共享石墨/硅/铅 + `newMaterials()`，供物品源菜单 / 核心白名单 / 后续配方使用喵。
- `register(IEventBus)` 注册到 mod 事件总线喵。

### 物品模型 JSON `assets/blockdustry/models/item/{name}.json` 喵

- 11 个新物品全部 `parent: minecraft:item/generated`，`layer0: blockdustry:item/{name}`（自动被 MC 物品渲染加载，无需额外注册）喵。

### lang 中英 `assets/blockdustry/lang/zh_cn.json` / `en_us.json` 喵

- 新增 11 条 `item.blockdustry.{name}`（中文/英文对照，见上表）喵。

### 改动 `BlockdustryBlocks.java` 喵

- `ITEMS_TAB` 创造栏 items tab：在石墨/硅/铅基础上追加 11 个新材料（`output.accept(BlockdustryItems.XXX)`）喵。

### 改动 `ItemSourceBlockEntity.java`（物品源产物设置）喵

- 产物由 `cycleProduct()` 右键循环改为 `setProduct(Item)` 菜单点选（校验在 `allMaterials()` 内），客户端同步 via sendBlockUpdated 喵。

### 改动 `CoreBlockEntity.java`（isWhitelisted 同步）喵

- 核心白名单由「仅煤+石墨」扩展为全部迁移材料（`allMaterials()` 惰性缓存进 `WHITELIST` Set），使物品源产物可入核心共享池喵。

### 改动 `Blockdustry.java` 喵

- 构造函数在 `BlockdustryBlocks.register` 后追加 `BlockdustryItems.register(modEventBus)` 喵。

### 改动 `ItemSourceBlock.java` 喵

- 空手右键改为客户端打开物品源菜单（Screen），服务端仅消费交互喵（详见 `^T22_材料调整.md`）喵。

## 4. 编译验证 喵

- `./gradlew compileJava` **BUILD SUCCESSFUL**（仅存既有 `@EventBusSubscriber bus()` 过时警告，与本次改动无关）喵。
