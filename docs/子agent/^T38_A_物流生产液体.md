## 备注区（迁移特别小心点，均基于真实源码）喵

1. **pulverizer 尺寸纠正（重要）**：主 agent 提示「pulverizer 是 2×2」，但源码 `Blocks.java:1293` 定义**无 size 字段** → 继承 `Block.size=1`（`world/Block.java:215`），且原版贴图 `assets-raw/sprites/blocks/production/pulverizer.png` 实测 **32×32px**（同目录 2×2 的 kiln=64px、3×3 的 multi-press=96px）→ **pulverizer 是 1×1**。迁移按 1×1 做，勿做 2×2 占地喵。
2. **melter 同为 1×1**：`Blocks.java:1218` 无 size，亦为 1×1（视觉看起来大但占地一格）。同理 melter 输出的是**液渣**（liquid），不是物品，需液体系统。
3. **两个 Separator 子类（separator/disassembler）**：产物是**随机概率表**（`results = with(...)`），迁移时要实现"按表随机掉一个"，不是固定产物；且二者都耗液渣，spinner 旋转盘动效（`-spinner, 3, true`）。
4. **液体依赖分组**：所有 liquid 类 12 块 + 产/耗液体的 crafting/production 块（melter、separator、disassembler、cryofluid-mixer、spore-press、coal-centrifuge、multi-press、water-extractor、oil-extractor、cultivator）**都依赖液体系统**。即使批1C/1D 先写了配方机，液体未就绪前这些块无法跑通（建议配方机先做但液体交互留接口）。
5. **mass-driver（高难）**：核心是远程目标联动——多个 mass-driver 互相链接、炮管 rotateSpeed 追踪目标、装填 120 物品后以 reload=200 抛射（range=440）；shootEffect/shokeEffect/receiveEffect 三个特效；**需注意 multiplayer 同步目标与抛射体**。3×3 需 Corner。
6. **payload-conveyor/payload-router（前置缺失）**：属 Category.units，运输"载荷"（单位/方块），Blockdustry 当前没有 payload 实体系统，**整组前置未建**，不应在早期排期。
7. **phase-conveyor 中文名是「相织布传送带桥」**（bundle 1968/2006 行），它是 ItemBridge 桥，不是普通带；`envEnabled|=space`（太空可运行）。phase-conduit 同理是「相织布导管桥」。phase-weaver 才是「相织布编织器」，三个名字容易混。
8. **unloader 需 config 交互**：`Unloader`（storage 包）靠 config 选物品，中心区域按物品色染色（`-center` region）；组属性 `BlockGroup.transportation`。Jade 上最好显示当前选中物品。
9. **AttributeCrafter 系（silicon-crucible/cultivator）**：silicon-crucible 默认 attribute=heat、boostScale=0.15；cultivator attribute=spores、maxBoost=2，二者都要在迁移时做"周围地形 attribute 加成"判定（cultivator 还 envRequired spores，须在孢子区）。
10. **SolidPump/Fracker 地形判定**：water-extractor 须建在水上（envRequired groundWater + attribute=water）；oil-extractor 须建在油区（baseEfficiency=0 + attribute=oil），无油田区块时效率为 0，需要地形检测逻辑。两者都有旋转钻头/叶片（rotatorRegion/topRegion）。
11. **导管渲染是瓦片拼接**：Conduit 用 `blendbits`/botRegions/topRegions 按四邻 blend 拼接（drawCached），迁移时最容易出的问题是方向/连接处贴图错乱；liquidRouter 用 drawTiledFrames 按液量铺液面。
12. **液体爆炸/易燃系数**：conduit 系都设了 `explosivenessScale/flammabilityScale`（导管/路由是 10/20~20/120），被打爆会爆出液体，迁移时如需复刻爆炸液溅要带上。
13. **堆叠运输**：plastanium-conveyor 是 StackConveyor，itemCapacity=10 成堆搬运，与普通 1 格 1 物品传送带逻辑不同，需专门实体与堆叠贴图（`@-stack`）。
14. **`rotate=false` 的 cryofluid-mixer**：明确 `rotate=false`，贴图方向固定；lightLiquid=冷冻液，DrawLiquidTile 带 drawLiquidLight=true 发光，方块自带光照。
15. **批1C/1D 的 P0 块里有液体依赖**：multi-press（耗水）、spore-press（产油）、coal-centrifuge（耗油）虽被列为批1C剩余，但都依赖液体，建议与批5A 液体系统联动排期，或先完成配方/物品部分、液体部分留接口。
