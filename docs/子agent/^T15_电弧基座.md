# T15 电弧炮 arc 基座模型丢失修复喵

> 修复「arc 基座黑紫/透明、无基座渲染」问题喵。
> 根因：`blockstates/arc.json`（与 `fuse.json`）的变体键用了**裸键**（`"nw"`、`"c"`…），
> 而 MC 1.21.1 的 blockstate 变体键必须为 `property=value` 形式（`"corner=nw"`…），
> 裸键会被 `BlockStateModelLoader.predicate()` 抛 `Unknown blockstate property`，
> 全部 9 个 corner 变体加载失败 → 方块落回 `missingModel`（黑紫棋盘/不渲染）喵。

---

## 1. 现象喵

- arc（1×1 电弧炮塔）基座渲染为黑紫/透明/无基座，仅 BER 画的转盘正常喵
- fuse（3×3 火焰炮）同样受影响（用户未单独报，但日志确认同样报错）喵

## 2. 根因分析喵

### 2.1 blockstate 变体键格式喵
- MC 1.21.1 `BlockStateModelLoader.predicate()`（`net.minecraft.client.resources.model.BlockStateModelLoader.java:207-243`）：
  - 变体键按 `,` 拆段，每段按 `=`（limit 2）拆 `property=value` 喵
  - 若该段不含 `=`（裸键如 `nw`），`getProperty("nw")` 为 null，且 `s1` 非空
    → `throw new RuntimeException("Unknown blockstate property: 'nw'")`（见第 223-224 行）喵
  - 异常被外层 catch 吞掉并 warn，该变体不产生任何匹配 → 所有 corner 状态落 `missingModel` 喵

### 2.2 现场证据（run/client/logs/latest.log）喵
```
Exception loading blockstate definition: 'blockdustry:blockstates/arc.json' ... for variant: 'nw': Unknown blockstate property: 'nw'
Exception loading blockstate definition: 'blockdustry:blockstates/arc.json' missing model for variant: 'blockdustry:arc#corner=nw'
```
- fuse.json 同样报 9 条 `Unknown blockstate property` + 9 条 `missing model` 喵

### 2.3 对比喵
- 工程内其他正常 blockstate（scatter/core/drill/turret 等）全部用 `"corner=nw"` 形式喵
- 仅 arc.json 与 fuse.json 用了裸键（T14 任务新建文件时写错）喵

## 3. 修复内容喵

只改资源 JSON，不动 Java/贴图喵。

| 文件 | 改动 |
|---|---|
| `src/main/resources/assets/blockdustry/blockstates/arc.json` | 9 个变体键 `nw/n/ne/w/c/e/sw/s/se` → `corner=nw`… 全部映射 `blockdustry:block/arc` 喵 |
| `src/main/resources/assets/blockdustry/blockstates/fuse.json` | 9 个变体键加 `corner=` 前缀，映射到 `blockdustry:block/fuse_nw`…（九宫格模型）喵 |

- `models/block/arc.json`（全量基座：turret_side 侧面 + arc_base 顶面）与贴图 `arc_base.png`（32×32 全不透明）、`turret_side.png`（64×64）、`textures/entity/arc_top.png`（转盘）均存在且引用正确，无需改动喵

## 4. 校验喵

- 全部 arc/fuse JSON 经 `python json.load` 合法喵
- 所有 blockstate 变体键均带 `corner=` 前缀；所有模型引用（`models/block/*.json`）与贴图引用（`textures/block|entity/*.png`）存在喵
- 全工程 blockstates 扫描：已无任何裸键变体喵

## 5. 验证方式喵

- 重新构建/运行 `runClient` 后，放置 arc：
  - 基座应为完整方块（turret_side 侧面 + arc_base 顶面），不再黑紫/透明喵
  - 转盘由 `ArcBlockEntityRenderer` 在 y≈1.02 叠画 arc_top，正常喵
- 日志不再出现 `Unknown blockstate property` / `missing model` for `arc.json`/`fuse.json` 喵
