# T25 科技树彻底重做（从零实现，数据/机制/UI 100% 按 Mindustry）阶段产出喵

## 目标喵
把 Blockdustry 科技树从「v1 多父 Java 静态注册 + 背包消耗 + MC 物品图标」彻底重做为「Mindustry TechNode 单父树 + 队伍共享资源消耗 + Mindustry 原版贴图 UI」，其余能沿用的全部按 Mindustry 喵。

| 文件 | 改动喵 |

## 二、存档与多人同步喵
- `research/ResearchSavedData.java` **不变**：SavedData 挂 overworld（`overworld().getDataStorage()`），跨维度共享；`unlocked` 集合 + `progress` 表，每处变更 `setDirty()` 落盘喵。
- `research/ResearchNetwork.java` **更新**：注册新增 `ResearchStoragePayload`；登录/开屏/研究后广播全量状态；研究后按玩家逐人广播各自队伍共享池存量喵。
- 解锁沿父链递归（镜像 Mindustry `ResearchDialog.unlock`）+ 免费空需求子节点自动解锁（`checkAutoUnlocks` 简化版）喵。

## 三、门控（服务端权威兜底）喵
- `research/ResearchGateHandler.java` **不变**：`BlockEvent.EntityPlaceEvent` 服务端拦未解锁建筑（`instabuild` 创造绕过），取消放置 + 提示 `blockdustry.research.locked`；Mindustry 只在 UI 层过滤，MC 联机必须服务端拦喵。

## 四、研究消耗 = 扣队伍共享资源（用户要求唯一偏离 Mindustry）喵
- `research/ResearchManager.java` **重写**：`spend()` 从 `BlockdustryTeamStorage.get(level, team).take(item, gap)` 扣料（核心共享池，**非背包**），队伍 = `BlockdustryTeams.getTeam(player)`，DERELICT 兜底回退 SHARDED（与网络查询核心物资同款语义）喵。
- `team/BlockdustryTeamStorage.java` **更新**：`Storage` 新增批量 `take(Item, int)`（一次取多个，避免逐件 O(n)）喵。
- 客户端研究面板显示队伍共享池存量（`ResearchStoragePayload` 同步，显示「剩余/需求」）喵。
