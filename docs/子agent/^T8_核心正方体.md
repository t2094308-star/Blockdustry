# T8 核心正方体（core 模型增高 3×3×3）阶段产出喵

## 目标喵

把核心（core，3×3×1）的方块模型从 1 格高改为 3 格高（from[0,0,0]→to[16,48,16]），使视觉成为 3×3×3 正方体（高度=宽度），并同步队伍染色渲染与选中框喵。不触碰共享注册文件（`BlockdustryBlocks.java`/`BlockdustryClient.java`）喵。

## 结论/产出喵

### 1. 模型改动（9 个 `models/block/core_{corner}.json`）喵

每个 corner 模型改为单个 element `from [0,0,0]` → `to [16,48,16]`（3 格高）喵：

- **顶面 `up`**：UV 3×3 裁剪**保持不变**（9 格各切 1/3×1/3），贴图 `blockdustry:block/core`，顶面从 y=1 升到 y=3（模型 y=48）喵。
- **四面 `north/south/east/west`**：贴 `blockdustry:block/core`（core.png，任务「core.png 或深色」的第一方案），用「每格切 1/3 列、V 0..16 满高」的 UV 让整张 96×96 core 纹理以均匀 2px/单位比例绕在立方体侧面（3 格拼 1 张纹理，无拉伸）喵。
- **底面 `down`**：`[0,0,16,16]` 满贴图（隐藏面，无碍）喵。
- particle 仍是 `blockdustry:block/core` 喵。

UV 规则（以格坐标 cx=列/dx、dz=行 推导，基于 1.21.1 FaceBakery 逐顶点赋 UV 的映射）喵：

| 面 | UV（`[u1,v1,u2,v2]`） | 说明 |
|----|----------------------|------|
| up | `[cx*16/3, dz*16/3, (cx+1)*16/3, (dz+1)*16/3]` | 顶面裁剪，与原实现一致 |
| north | `[(cx+1)*16/3, 0, cx*16/3, 16]` | 西=列起点，东=列终点（不镜像） |
| south | `[cx*16/3, 0, (cx+1)*16/3, 16]` | 西=列起点（不镜像） |
| west | `[dz*16/3, 0, (dz+1)*16/3, 16]` | 北=列起点，南=列终点 |
| east | `[(dz+1)*16/3, 0, dz*16/3, 16]` | 北=列起点（镜像同 west） |
| down | `[0,0,16,16]` | 满贴图 |

生成脚本（临时 `gen_core.py`，json.dump 输出）已跑并验证：9 个文件 JSON 合法、blockstate 9 个 variant 引用全部存在、from/to/面数正确喵。

### 2. 渲染同步喵

- `client/CoreBlockEntityRenderer.java`：队伍染色层 `pose.translate(0, 1.001, 0)` → `pose.translate(0, 3.001, 0)`（顶面升到 3 格高，防 z-fighting），3×3 平面位置与 UV 不变喵。
- `building/CoreBlockEntity.java`：**无改动**（1.21.1 已移除 `BlockEntity.getRenderBoundingBox`，改用渲染器 `shouldRender` 距离裁剪，故不再需要扩包围盒；曾尝试加该方法导致「不覆盖超类型方法」编译错，已回退）喵。
- `client/BlockdustryHighlightHandler.java`：选中框对 core 方块高度改为 `size`（3 格），其余多格建筑仍 1 格；仅加一个 import `BlockdustryBlocks` 喵。

### 3. 风险/注意喵

- **碰撞与放置不变**：建筑实体仍占 1 格高（3×3×1 放置），只视觉增高 3 格；玩家可走进/站在上方 2 格视觉内（任务接受）喵。
- **相邻方块遮挡**：立方体侧面/顶面延伸进 y+1、y+2 空气格，放置方块会正常遮挡相应面（含在立方体内部叠放会穿模，属已知取舍）喵。
- **内缝消除**：9 格彼此为 solid 全立方体，邻格面被正常剔除，无内部 z-fighting 喵。
- **并发占用冲突**：`git status` 显示同仓库有其它并发 agent 的 WIP（`possession/`、`ScatterBlockEntity`、`FlakBulletEntity`、`TurretBlockEntity` 等），`./gradlew compileJava` 因这些文件报 9 个「找不到符号」错误（与本次改动无关）。我的 3 个 Java 文件与 9 个 JSON 均无编译错误喵。
- **换肤备选**：若 core.png 侧面观感不合意，把 `textures.side` 一行改 `blockdustry:block/drill_side` 并重跑生成即可（「深色」方案）喵。
