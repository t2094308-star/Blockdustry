# T7 装甲机制 阶段产出喵

## 目标喵
为 Blockdustry (NeoForge 1.21.1) 引入如 Mindustry 的 armor 固定减伤机制：炮弹命中活体/建筑时先按装甲折算伤害，伤害 = max(1, 原始伤害 - 装甲)，并提供 dagger 演示装甲值喵。

## 结论/产出喵

### 一、设计喵
Mindustry 中单位/建筑有 `armor` 字段，为**固定减伤**而非百分比：`最终伤害 = max(1, 原始伤害 - armor)`喵。
本 mod 现有伤害路径仅有炮弹一处（`BlockdustryBulletEntity`）：命中活体走原版 `hurt()`，命中建筑走前置库 `BlockHealthApi.damage()`喵。
方案：
1. 新增静态工具 `BlockdustryArmor`，提供 `getArmor(Entity)` / `getArmor(BuildingEntity)` / `reduceDamage(raw, armor)` 与实体装甲注册表喵。
2. 单位装甲走「EntityType → 装甲值」注册表（默认 0，未注册实体无装甲；dagger 演示值 3），**不改** `DaggerUnitEntity` 字段喵。
3. 建筑装甲加在基类 `BlockdustryBuildingEntity` 的 `armor` 字段（默认 0），带 getter/setter 与 NBT 持久化喵。
4. 炮弹命中处调 `BlockdustryArmor` 折算后再交给 `hurt()` / `BlockHealthApi.damage()`；因前置库 `BlockHealthApi.damage` 无 armor 参数，故在调用前自己折算喵。

### 二、伤害折算公式喵
```
最终伤害 = max(1, 原始伤害 - 装甲)        // 最少 1 点，防无限无敌喵
```
- 原始伤害 9（duo 铜弹），目标装甲 3 → 最终 6 喵
- 原始伤害 9，目标装甲 12（> 伤害） → 最终 1（每次至少 1 点）喵
- 装甲默认 0 → 最终伤害 = 原始伤害，行为与改造前完全一致喵

### 三、改动文件清单喵
| 文件 | 类型 | 改动 |
|---|---|---|
| `src/main/java/com/blockdustry/entities/BlockdustryArmor.java` | 新增 | 静态工具：实体装甲注册表、`getArmor`、`reduceDamage`、`applyToEntity/applyToBuilding`，dagger 默认装甲 3 |
| `src/main/java/com/blockdustry/entities/BlockdustryBulletEntity.java` | 最小改动 | 命中活体 `target.hurt(generic, BlockdustryArmor.applyToEntity(target, damage))`；命中建筑 `BlockHealthApi.damage(..., BlockdustryArmor.applyToBuilding(building, damage), ...)` |

### 四、独立代码文件（已落地）喵
`D:\Blockdustry\仓库\src\main\java\com\blockdustry\entities\BlockdustryArmor.java`（内容见源码）喵。

### 五、dagger 装甲示例值喵
- Mindustry dagger 原版 armor = 0（超脆）喵。
- 本 mod 演示值取 **3**：duo 铜弹 9 伤害 → 命中 dagger 变为 6，直观可感又不会太过抗揍喵。
- 建议后续：turret 建筑可 `setArmor(2f)`、core 建筑可 `setArmor(5f)`（在各自构造函数里设置即可）喵。

### 六、集成注册点（主会话需要做的）喵
无强制注册要求：`BlockdustryArmor` 在首次 `getArmor` 时惰性装入 dagger 演示装甲 3，开箱即用喵。
如需为其他单位/建筑配置装甲：
- 单位：在任意初始化处调 `BlockdustryArmor.setEntityArmor(BlockdustryEntities.X.get(), 数值)`（例如主类 `commonSetup`）喵。
- 建筑：在建筑实体构造函数里 `setArmor(数值)` 喵。
