# T16 电力节点倒角 阶段产出喵

## 目标喵
给 `power_node` 方块模型（当前 `cube_all` 单立方体）加「角倒角」：16×16×16 立方体 8 个角各切掉 5px 三角锥区域，形成去角立方体，每个面 4 角各有倒角缺口喵。

## 方案选择喵
MC 方块模型 element 只能是**轴对齐长方体**，无法直接表达三角锥斜面；element `rotation`（斜放）的 UV 会崩坏（见 `docs/坑/方块模型.md` §4 传送带旋转元素坑），故不走 BER/旋转。采用**方案 a：多 element 竖直切角**喵。

- 每轴切分 `[0, 5, 11, 16]`（三段：0~5 / 5~11 / 11~16），形成 3×3×3=27 个格喵
- 去掉 8 个「角格」（三轴索引都在 {0,2} 的格，即 5×5×5 角落立方体），保留 19 格喵
- 视觉：每个面由 16×16 方形裁去 4 个角部 5×5 方块 → 呈八边形；每角露出 3 个内壁面（同一 power_node 贴图）喵
- 不再叠加方案 c（阶梯 45°）：5px 相对 16px 已切 31%，倒角感明显；若后续目测觉得太方，可在角区 0~5 再分层偏移加阶梯喵

## element 生成喵
保留格判定：`not (i in (0,2) and j in (0,2) and k in (0,2))`，共 27-8=19 格。生成代码片段（行内执行，未留脚本文件）喵：

```python
import json
SEGS = [0, 5, 11, 16]
FACE_ORDER = ["north", "south", "east", "west", "up", "down"]
els = []
for i in range(3):
    for j in range(3):
        for k in range(3):
            if i in (0, 2) and j in (0, 2) and k in (0, 2):
                continue  # 8 个角格去掉喵
            f = [SEGS[i], SEGS[j], SEGS[k]]
            t = [SEGS[i+1], SEGS[j+1], SEGS[k+1]]
            faces = {face: {"uv": [0, 0, 16, 16], "texture": "#all"} for face in FACE_ORDER}
            els.append({"from": f, "to": t, "faces": faces})
model = {"textures": {"all": "blockdustry:block/power_node"}, "elements": els}
json.dump(model, open(r"D:\Blockdustry\仓库\src\main\resources\assets\blockdustry\models\block\power_node.json", "w", encoding="utf-8"), ensure_ascii=False, indent=2)
```

每个 element 6 面 UV 全用 `[0,0,16,16]`（16×16 模型空间 = 整张贴图，见坑文档 §3），`#all` 指向保留的 `power_node.png` 喵。

## 限制说明喵
- **无法真斜面**：element 只能是轴对齐长方体，三角锥/45° 斜面需 BER 手绘 quad 或 rotation（UV 崩坏）→ 用多长方体拼合近似喵
- **内部共面不 z-fighting**：相邻格共面处两面法线相反，MC 背面剔除只渲染朝向观察者的那一面；被遮挡的内面被深度测试正确隐掉（如从 -z 看，外侧 z=0 面先挡住内部 z=5 面）喵
- **坐标与 UV 校验**：19 element 坐标全在 [0,16]（符合 [-16,32] 上限），6 面 UV 全在 [0,16]×[0,16] 喵
- **性能**：19 元素 × 6 面 = 114 面，方块模型可承受，无上限问题喵
