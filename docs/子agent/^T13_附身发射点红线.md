# T13 附身发射点对齐 + 移除红线 阶段产出喵

## 目标喵
修复「附身双管炮」两个问题：
1. **发射位置与瞄准位置不一致**：附身开火时子弹弹道与玩家准星对不上喵。
2. **附身视野里常驻的奇怪红线**：用户倾向移除或极简喵。

## 排查结论（问题一：瞄准点/弹道对不上）喵
**根因不在 `fireAt` 的横偏，而在 `tickManual` 的瞄准高度基准喵。**
- 附身时玩家被 `TurretPossessManager` 钉在炮塔正上方的空气位（`cameraSpot`），脚底在塔顶（y+1）、眼睛约 y+2.62 喵。
- 原 `tickManual` 把弹道终点设为 `worldPosition.getCenter() + dir*range`（炮塔中心高度 y+0.5），即子弹恒在玩家准星视线下方约 2 格处收敛——弹道与玩家瞄准位置对不上喵。
- `fireAt` 本身正确：`spawn = center + dir*shootY + perp*(±spread) + (0,0.3,0)`（双管横偏在炮口），`fireDir = aim - spawn` 归一化后朝向 target，弹道终点能落到 target 处；问题只是 target 的高度基准用了炮塔中心而非玩家眼睛喵。

## 修复（问题一）喵
- `TurretBlockEntity.tickManual()`：把瞄准点从 `worldPosition.getCenter() + dir*range` 改为 `possessorEye() + dir*range`，让弹道终点落在玩家准星视线 `range` 格处喵。
- 新增私有方法 `TurretBlockEntity.possessorEye()`：在服务端按 NBT 标记 `bd_possessing`（由 `TurretPossessManager` 维护）在炮塔周围 7 格内找附身玩家，取其 `getEyePosition()`；找不到时回退 `center + (0, 2.12, 0)`（塔顶站位常见值）喵。
- 双管横偏保留：`fireAt` 从对应炮管口（±spread）沿「炮口→瞄准点」方向发射，与玩家看到的瞄准线一致，弹道终点在瞄准点喵。
- 改动仅涉及 `TurretBlockEntity.java`（新增 `import ServerLevel/ServerPlayer` + 改一行 + 新增一方法），未动网络包/管理器喵。

## 修复（问题二：红线）喵
- `TurretPossessHandler.onRenderLevel()`：彻底移除穿透地形的红色瞄准线绘制块（用户倾向移除），保留：
  - 蓝色射程圈（地面 y 平面、半径=射程，仍画穿透视野）喵；
  - HUD 绿色准星十字与操作提示（`onRenderGui` 不动）喵。
- `AIM_LINES` 自定义渲染类型保留（射程圈仍用）喵。

## 编译验证喵
`./gradlew compileJava --offline` → BUILD SUCCESSFUL，仅 4 个与本任务无关的既有 `EventBusSubscriber.bus()` 弃用警告喵。

## 风险/备注喵
- `possessorEye()` 在开火瞬间才调用（每 reload tick 一次），开销极小；附身玩家始终被钉在炮塔上方，7 格范围可靠命中喵。
- 若未来玩家站位逻辑变化（如相机不钉塔顶），回退值 `2.12` 需同步；主路径按实际玩家眼睛计算，不受影响喵。
- 弹道终点落在准星视线 `range` 格处，近处目标（<10 格）弹道会比准星略低（收敛特性），远距离命中更准喵。
