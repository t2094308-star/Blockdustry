> 机制与数据优先；模型/贴图用 Mindustry 原版拷贝（不重绘）。核心是 agent 协调/交流迭代/从坑里爬出来喵。

## 一、共享文件纪律（最高优先级，防并行冲突）

| 文件 | 谁写 |
|---|---|
| `Blockdustry.java`/`BlockdustryClient.java`/`BlockdustryBlocks.java`（tab+组血量）/`ResearchNodes.java`/`ResearchIcons.java`/`lang/*.json` | **仅主会话**，子 agent 绝不改 |

| `D:\Blockdustry\任务\T{编号}_{名称}.md` | 每个 agent 开工前登记占用 |

**每个 agent 交付物**：① 自包含注册类 `XxxRegistrar.java`（+Block/BE/Renderer）② 新资源（唯一文件名）③ 整合清单 `^P1_批X_{agent}整合清单.md`（精确到主会话挂载点）④ lang 片段 ⑤ 任务登记 ⑥ 进度报告（交流迭代）。

## 四、依赖顺序与优先级

材料（已完成）→ 生产/物流 → 电力 → 防御/墙体 → 炮塔 → 单位 → 高级。
P0（第 1-2 轮）：1A/1B/1C/1E/1F 基础批（自包含、无液体无 size4）。
Frame-0：size4-5 扩展 + 液体注册表（独立 agent，不与内容批并行）。
优先级：基础 > 防御 > 炮塔 > 单位（依赖 Blockbench 单位模型）> 液体 > 逻辑。

## 五、主会话整合流程（每批完成后）

1. 收集该批所有 agent 的整合清单 + lang 片段；
2. 挂载：`Blockdustry.java` 加 `XxxRegistrar.register(modEventBus)` → tab `accept` → `ResearchNodes.all()` 加节点 → `BlockdustryClient` 渲染注册 → `ResearchIcons` case → lang 合并 → 多格组血量；
3. 校验：parentId 全集存在、unlockBlock 已注册、tab 无重复；
4. `./gradlew compileJava` 修错（只读既有弃用警告）；
5. `bash tools/launch_game.sh` 冒烟：创造栏新项/放置/`research unlockall`/科技树 UI/Jade/组血量；
6. 更新 `D:\Blockdustry\待办.md` + `D:\Blockdustry\任务`（完成+清占用）+ 坑文档补新坑。
