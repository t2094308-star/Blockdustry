# T13 传送带侧面贴图 阶段产出喵

## 目标喵
为 Blockdustry 传送带（全 6 种 variant：straight/corner/corner_right/t/cross/none）自绘一张 Mindustry 风格**侧面贴图**，替换当前侧面占位引用 `minecraft:block/stone`，不改 Java 喵。

## 现状分析喵
全部 `models/block/conveyor_*.json` 结构一致：单一元素 `[0,0,0]~[16,4,16]`（底座高 4px），up 面用 `#belt`（对应 32×128 动画带面贴图），north/south/east/west 与 down 面用 `#side`，此前 `#side` 引用 `minecraft:block/stone`（原版石纹占位，非传送带观感）喵。

### 关键几何：可见侧脸只占贴图顶部 1/4 喵
- 侧面面片 16 宽×4 高，UV 为 `[0,0,16,4]` → MC 按「纹理尺寸/16」逐轴缩放，**顶部 4/16 = 25% 纵向**被采样喵
- 64×64 贴图时，可见带 = **顶部 16 行**（行 0~15，v=0 对应方块顶部），行 16~63 仅在 down 面（方块底面，通常不可见）显示喵
- 故贴图顶部 16 行需完整表达「低矮基座 + 带面侧缘」层次，其余行保持不透明深灰即可喵

## 贴图设计喵
**新贴图：64×64、RGBA、全不透明（alpha 255）、7 色调色板取自 Mindustry `conveyor-0-0.png` 侧缘视觉**。自顶向下层次（每 4 行 ≈ 模型 1px）喵：

| 行区间 | 模型 px | 颜色 | 视觉喵 |
|---|---|---|---|
| 0~2 | 顶 | `(152,154,164)` 带面亮色 | 带面侧缘喵 |
| 3 | 顶 | `(134,136,146)` 带面底缘 | 带底暗一线喵 |
| 4~7 | 第 2 | `(110,112,128)` 中灰 | 基座唇口过渡喵 |
| 8~11 | 第 3 | `(74,75,83)` 深灰金属 | 基座主体喵 |
| 12~14 | 底 | `(62,63,70)` 深灰稍暗 | 基座下部喵 |
| 15 | 底 | `(52,53,59)` 阴影 | 底缘阴影喵 |
| 16~63 | down 面 | `(74,75,83)` 深灰 | 方块底面填充喵 |

调色板与 Mindustry 俯视帧主色（亮 152,154,164 / 中 110,112,128 / 暗 74,75,83）逐像素一致，不做旧、无铆钉磨损，风格与全模组统一喵。

### 生成代码片段（PIL 12.x，行内执行未留脚本文件）喵
```python
from PIL import Image
SIZE = 64
img = Image.new("RGBA", (SIZE, SIZE), (0, 0, 0, 0))
px = img.load()
BELT_LIGHT = (152, 154, 164, 255)  # 带面侧缘亮色喵
BELT_EDGE  = (134, 136, 146, 255)  # 带面底缘暗一线喵
LIP_MID    = (110, 112, 128, 255)  # 基座唇口过渡喵
FRAME      = (74, 75, 83, 255)     # 深灰金属基座喵
FRAME_DARK = (62, 63, 70, 255)     # 基座下部稍暗喵
SHADOW     = (52, 53, 59, 255)     # 底缘阴影喵
for y in range(16):
    c = BELT_LIGHT if y <= 2 else BELT_EDGE if y == 3 else \
        LIP_MID if y <= 7 else FRAME if y <= 11 else FRAME_DARK if y <= 14 else SHADOW
    for x in range(SIZE): px[x, y] = c
for y in range(16, SIZE):
    for x in range(SIZE): px[x, y] = FRAME
img.save(r"D:\Blockdustry\仓库\src\main\resources\assets\blockdustry\textures\block\conveyor_side.png")
```
