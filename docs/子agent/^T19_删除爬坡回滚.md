# T19 删除爬坡（上下坡传送带）回滚喵

## 目标喵

按主会话决定：**删除之前传送带爬坡（上下坡）有关的全部改动，垂直升降全靠提升机**喵。回滚对象是 T16 上下坡逻辑 + T17 上下坡模型两件事，保留独立的 T18 提升机顶部直连传送带功能（与「上升全靠提升机」方向一致）喵。

---

## 一、回滚内容喵

| 项 | 回滚前 | 回滚后 |
|---|---|---|
| `ConveyorBlock.java` | 有 `Slope` 枚举(FLAT/UP/DOWN) + `SLOPE` 属性 + 放置/邻居判坡逻辑（detectSlope/refineSlope/updateSlope） | 恢复纯平面：仅 `FACING` + `CONN`，放置/邻居只更新连接喵 |
| `ConveyorBlockEntity.java` | 有 `getSlope()`、坡道出口 `frontPos` 按坡度切 `.above()/.below()`、`directionOf` 对角尾插（背向+下/上） | 恢复平面：`frontPos = pos.relative(facing)`，移除对角尾插；**保留 T18 提升机顶部直连**喵 |
| `client/ConveyorBlockEntityRenderer.java` | 物品 y 随 progress smoothstep 插值（UP 0.25→1.0 / DOWN 反向） | 恢复固定带面高 0.25，无坡度插值喵 |
| `blockstates/conveyor.json` | 756 variant（含 `slope=flat/up/down`，且 straight/none 的 up/down 指向 conveyor_up/down 模型） | 回退 252 variant（9 corner × 4 facing × 7 conn），slope 维度整体移除喵 |
| `models/block/conveyor_up.json` | 上坡阶梯模型（T17 新增） | 已删除（src + build）喵 |
| `models/block/conveyor_down.json` | 下坡阶梯模型（T17 新增） | 已删除（src + build）喵 |

---

## 二、保留内容（非爬坡、勿误删）喵

1. **T18 提升机顶部直连传送带**：`ConveyorBlockEntity.directionOf` 里 `source instanceof ElevatorBlockEntity && worldPosition.below().equals(source.getPos())` → 视为尾插。这是「电梯顶正上方叠传送带即可直连」的关键，与「上升全靠提升机」一致，**保留**喵。
2. **T18 顺带的编译修复**：`ResearchSavedData.java` 的 `SavedData.Factory` 签名修正，与爬坡无关，**保留**喵。
3. 传送带本体、Router、物品源、提升机等一切既有功能不受影响喵。
