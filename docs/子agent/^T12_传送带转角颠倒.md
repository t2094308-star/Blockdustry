# T12 传送带转角上下颠倒 修复产出喵

## 目标喵
修复「面向东西南北任意一方铺设传送带，**向右转**时转角处的传送带上下颠倒」问题喵。

## 根因喵

### 1. conveyor-1 原版贴图是「左转」贴图喵
逐像素分析 `conveyor_corner.png`（T11 已换成 Mindustry conveyor-1，经验证与 `conveyor-1-0.png` diff=0）喵：

- 朝东渲染时（Mindustry rotation=0=east），带面主体从**贴图顶缘（北）**进入，弧线向右，从**贴图右缘（东）**出去，即「**北进东出**」喵。
- 在 MC 中 `facing=east`（y=0）up 面原样显示时，同样为北进东出喵。
- 北 = facing 的**逆时针侧**（getCounterClockWise），即原版 conveyor-1 = 从 facing 逆时针侧进 = **左转**贴图喵。

### 2. Mindustry 左/右转靠贴图垂直翻转区分，MC 只有一套贴图喵
Mindustry `Autotiler.transformCase`：
- `num=5`（前+右，逆时针侧进）→ conveyor-1 原版，`bits[0]=1` 无翻转喵。
- `num=4`（前+左，顺时针侧进）→ conveyor-1 **Y 翻转**（`blendsclY=-1`），`bits[0]=1` 喵。

即左转=原版、右转=垂直翻转（v 翻转）的镜像贴图喵。MC 此前只有一套原版左转贴图喵。

### 3. conn=corner 不区分左右转喵
`ConveyorBlock.computeConnection` 把「前/后 + 左/右」全部归为 `Connection.CORNER`，丢失「哪一侧连接」信息；blockstate 对所有 corner 变体用同一模型 + y 旋转，无法为右转选镜像贴图喵。

### 4. 结果：所有 facing 的「向右转」都上下颠倒喵
玩家「向右转」= 铺设方向顺时针转 90°，转角块从 facing 的**顺时针侧**（getClockWise）接带，需要「南进东出」等右转贴图；实际显示左转贴图（北进东出），v 方向反了 180° → 上下颠倒喵。

几何校验（原版左转贴图，facing→y：north=270/east=0/south=90/west=180）：
- 右转 facing=east（需南进东出）：y=0 显示北进东出 ✗（颠倒）喵。
- 右转 facing=west（需北进西出）：y=180 显示南进西出 ✗（颠倒）喵。
- 左转 facing=west（需南进西出）：y=180 显示南进西出 ✓ 喵。
- 左转 facing=north/south/east 同理 ✓ 喵。

即左转全部正确、右转全部颠倒，与用户报告完全一致喵。

## 修复喵

1. **生成右转镜像贴图** `conveyor_corner_right.png` = conveyor-1 垂直翻转（每帧 32×32 独立 FLIP_TOP_BOTTOM，拼回 32×128 RGBA，帧序不变），mcmeta 同原图（frametime=3, frames=[0,1,2,3]）喵。
2. **新建模型** `models/block/conveyor_corner_right.json`：同 conveyor_corner.json 结构，`#belt`/`particle` 指向 `conveyor_corner_right` 喵。
3. **Java** `ConveyorBlock.Connection`：`CORNER` 拆出 `CORNER_LEFT("corner_left")` / `CORNER_RIGHT("corner_right")`，保留 `CORNER("corner")` 兼容旧存档；`computeConnection` 侧向判断——`l`（getClockWise 顺时针侧）连接 → `CORNER_RIGHT`，`r`（getCounterClockWise 逆时针侧）连接 → `CORNER_LEFT` 喵。
4. **blockstate** `conveyor.json`：
   - `conn=corner_left` → `conveyor_corner`（原版左转贴图）喵。
   - `conn=corner_right` → `conveyor_corner_right`（镜像右转贴图）喵。
   - y 旋转表不变（north=270/east=0/south=90/west=180）喵。
   - 加回 `conn=corner` 兼容变体（映射 conveyor_corner 左转），旧存档加载不崩，方块被更新后自动迁移喵。
   - 变体数 180 → 252 喵。

右转 4 facing 校验（镜像贴图 + 原 y 旋转表）：
- facing=east y=0：镜像贴图=南进东出 ✓ 喵。
- facing=south y=90：旋转后=西进南出 ✓ 喵。
- facing=west y=180：旋转后=北进西出 ✓ 喵。
- facing=north y=270：旋转后=东进北出 ✓ 喵。
