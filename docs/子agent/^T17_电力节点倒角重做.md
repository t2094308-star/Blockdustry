# T17 电力节点倒角重做 阶段产出喵

## 问题诊断喵
T16 的 19-element 去角立方体在游戏里「像好多个小节点堆起来」：每个 element 每面整图采样 `uv:[0,0,16,16]`，power_node 贴图自带中央黄色节点，正面 5 个共面矩形各显示一个完整节点 → 一张脸 5 个节点 → 视觉分裂喵。

T17 初版（18 element + 外露面 UV 切片）消除了纹理重复，但**竖直切角**（挖 5×5×5 立方体空腔）在面上呈**方形缺口**，用户反馈「像掏走了一个立方体」，要求**真 45° 等边三角形斜面倒角**喵。

## 方案：cube_all 主体 + BER 手绘 8 角等边三角斜面喵
element 只能是轴对齐长方体（rotation 的 UV 崩坏见 `方块模型.md`），真 45° 斜面无法用 element 表达。故：
1. **方块模型回归 `cube_all`**：实心 16×16×16 立方体，6 面各显示一次完整 power_node 贴图（无纹理重复）喵
2. **BER 画 8 个等边三角形斜面**：每个角一个三角 quad，顶点在三条棱上距角 5 模型单位 → 切面平面过 (5,0,0)(0,5,0)(0,0,5)，三边均 5√2 **等边三角形**，法线 (1,1,1)/√3 朝外（45° 倒角观感）喵

斜面从 cube 角表面**沿外法线凸出 eps**（0.02 世界单位），盖住角部、防 z-fighting；`entityTranslucent`（无 cull 双面）+ 顶点全亮 `0xF000F0` + `OverlayTexture.NO_OVERLAY`（见 `坑/BER渲染.md` §1/§2），白纹理染色深灰 (110,112,128)（贴图侧边色，与材质一致），法线用真实朝外法线使 diffuse 光照有自然明暗喵。

## 几何验证喵
| 项 | 结果喵 |
|---|---|
| 切面等边 | 三边均 5√2（7.071），8 角全等边 ✓喵 |
| 法线朝外 | 每角法线 = 中心(8,8,8) 指向该角方向归一化，点积>0 ✓喵 |
| 坐标范围 | 三角形顶点全在 [0,16]，/16 转世界 [0,1] ✓喵 |
| 凸出 | 沿法线平移 0.02 世界单位，防与 cube_all 面 z-fighting ✓喵 |

## 实现变更喵
`PowerNodeBlockEntityRenderer` 扩展（原激光渲染保留）：
- 新增常量 `CHAMFER_TRIS`（8 角各 3 顶点模型坐标）、`CHAMFER_NORMALS`（8 角外法线归一化）、`CHAMFER_R/G/B`（深灰）喵
- `render` 开头（在激光提前 return **之前**）画 8 个斜面，保证无激光时斜面仍显示；激光逻辑不变，仍是唯一 `entityTranslucent` renderType 不交错不崩喵
- 新增 `drawChamfer`（模型坐标 /16 转本地世界 + 法线外移 eps）与带法线的 `vertex(float...)` 重载（激光原 `vertex(Vec3...)` 保留）喵
- **QUADS 对齐坑**：`entityTranslucent` 是 QUADS 模式，斜面若只画 3 顶点会破坏顶点缓冲对齐 → 后续 quad 顶点错乱，深灰色块乱画到多个面（用户反馈「部分面贴图崩坏」的根因）；必须 4 顶点退化 quad（v0,v1,v2,v0）凑满对齐喵
- 坐标：斜面用 LevelRenderer 传入 pose（已含 blockPos-cam），本地坐标直接画；激光沿用 `pushPose + setIdentity` 世界坐标喵

方块模型：`power_node.json` 改回 `cube_all` 父模型（`{"parent":"minecraft:block/cube_all","textures":{"all":"blockdustry:block/power_node"}}`）喵。

## 交接与风险喵
- 交接给主会话：建议 `bash tools/launch_game.sh` 跑 runClient 目测 8 角等边三角形斜面观感喵
- 已知行为：方块模型是实心 cube，BER 斜面凸出 0.02 盖角，观察者若贴近极小角度可能看到斜面边缘下 cube 角的一丝边缘（ε 级，几乎不可见）；可调 `eps`（0.008~0.02）或改斜面用 power_node 贴图深灰带纹理喵
- 若想更省渲染：方块模型可用「中心块 + 6 面」减少 cube 面数，但角部会露缝，不如 cube_all 稳妥喵
- 未触及 `build/` 下拷贝，由 Gradle 重新构建生成喵
