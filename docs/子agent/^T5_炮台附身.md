# T5 炮台附身 阶段产出喵

## 目标喵
实现「炮台附身」：玩家空手右键炮塔进入附身，视角锁定炮台（身体传送进炮塔、相机俯仰锁水平），玩家鼠标驱动炮塔转向、左键开火（覆盖自动 AI），潜行退出；附身后视野扩展到炮台射程，并绘制穿透地形的瞄准线/射程圈/准星喵。

## 结论/产出喵
- **方案**：服务端权威的「玩家传送进炮塔 + 炮塔手动模式」+ 客户端视角/输入接管 + 网络包驱动。
  - 附身时把玩家实体传送到炮塔内（`noPhysics` 防窒息、`noGravity` 防坠落、`invisible` 隐藏身体、每模组 tick 钉回防漂移），相机天然跟随玩家 → 视野自动扩展到炮塔周边已加载区块（duo 射程 20 格远小于默认渲染距离，天然满足「视野扩展到射程」）喵。
  - 炮塔切手动模式（`TurretBlockEntity` 加极小补丁），`tickAnchor` 分支到手动控制：向玩家给的角匀速转向、冷却就绪时沿水平方向开火，完全覆盖自动索敌 AI 喵。
  - 客户端鼠标水平转动 → 玩家 yRot → `aimYaw = 180 - yRot` 推导 → `TurretControlPayload` 节流发服务端；左键按住 → `fire=true` 驱动开火；潜行 0.25s → 发退出包喵。
  - 穿透视野：世界空间用「关深度测试」的自定义 `RenderType` 画水平瞄准线（红）与地面射程圈（蓝），可看穿地形；HUD 画绿色准星十字与操作提示喵。

## 附身交互喵
- **进入**：空手右键 `TurretBlockEntity`（服务端 `PlayerInteractEvent.RightClickBlock`），校验同队或 DERELICT 无主，`TurretPossessManager.toggle()` 进入喵。
- **控制**：鼠标水平旋转炮塔、左键开火（客户端 `InputEvent.InteractionKeyMappingTriggered` 取消攻击/使用键，避免敲方块）喵。
- **退出**：潜行（Shift）连按 0.25s；或玩家死亡/登出/炮塔被破坏时由服务端自动退出并还原喵。

## 穿透视野喵
- 附身后玩家实体在炮塔内，服务端以玩家为中心加载区块 → 射程内地形/目标自然可见（duo 射程 20 格 < 默认视距 8~12 区块）喵。
- 额外绘制（`RenderLevelStageEvent.AFTER_LEVEL`，自定义 `LINES_NO_DEPTH` 渲染类型，深度测试关闭）：
  - 炮塔底平面半径=射程的蓝色圈 → 直观显示「搜索范围」喵。
  - 炮口高度沿玩家视线的红色瞄准线（到射程末端）→ 穿透地形显示弹道喵。
- HUD（`RenderGuiEvent.Post`）画绿色准星十字 + 「炮台附身 · 左键开火 · 潜行退出」提示喵。
- 若未来炮台射程 > 模拟距离：只扩渲染、目标为已加载敌对（服务端不会为附身强制加载超视距区块，这是 MC 机制限制，见风险）喵。

```java

private boolean manualMode;
private float manualAimYaw;
private boolean manualFire;
```

在 `tickAnchor()` 第一行加分支（覆盖自动 AI）：

```java

    tickManual();
    return;
}
```

在类内加方法：

```java
// 附身控制入口喵
public void setManualMode(boolean manual) {
    this.manualMode = manual;
    if (manual) this.manualAimYaw = this.aimYaw;
    if (!manual) this.manualFire = false;
    sync();
}

public boolean isManualMode() {
    return manualMode;
}

// 玩家视角 yaw 换算出的炮塔目标角（度）喵
public void setManualAim(float yaw) {
    this.manualAimYaw = yaw;
}

// 请求开火（下一 tick 消费）喵
public void requestManualFire() {
    this.manualFire = true;
}

// 射程（穿透视野/状态包用）喵
public float getRange() {
    return RANGE;
}

// 手动模式 tick：后坐力衰减 + 匀速转向 + 冷却就绪开火（沿 aimYaw 水平方向）喵
private void tickManual() {
    float decay = 1f / RELOAD;
    recoilL = Math.max(0, recoilL - decay);
    recoilR = Math.max(0, recoilR - decay);
    recoilTop = Math.max(0, recoilTop - decay);
    aimYaw = moveToward(aimYaw, manualAimYaw, 10f);
    if (cooldown > 0) cooldown--;
    if (manualFire && cooldown <= 0) {
        // aimYaw 方向水平开火：dir = (-sinθ, 0, -cosθ)，预判点=射程端点（零速无预判）喵
        double rad = Math.toRadians(aimYaw);
        Vec3 dir = new Vec3(-Math.sin(rad), 0, -Math.cos(rad));
        Vec3 target = worldPosition.getCenter().add(dir.scale(RANGE));
        fireAt(target, Vec3.ZERO, barrel);
        if (barrel == 0) recoilR = 1f; else recoilL = 1f;
        recoilTop = 1f;
        barrel = 1 - barrel;
        cooldown = RELOAD;
        sync();
    }
    manualFire = false;
    if (Math.abs(aimYaw - lastSyncedYaw) > 2f) {
        lastSyncedYaw = aimYaw;
        sync();
    }
}
```

无需新 import（`Vec3` 已导入）喵。

## 风险/待人工排查喵
- **编译验证（已跑 `./gradlew compileJava --offline`）**：本任务 5 个新文件无编译错误；剩余 8 个错误中 6 个是 `TurretBlockEntity` 补丁缺失（`setManualMode/getRange/setManualAim/requestManualFire`，应用补丁即消），另 2 个（`ScatterBlockEntity.java:30`、`FlakBulletEntity.java:41`）是并行 agent 新建文件，**非本任务**，勿动喵。
- **`RenderLevelStageEvent` 无 `getMultiBufferSource()`**：穿透线改用 `Minecraft.getInstance().renderBuffers().bufferSource()` 画线 + `endBatch(AIM_LINES)` 按类型刷新（已编译通过）喵。
- **自定义 RenderType**：`RenderType.create` + `NO_DEPTH_TEST` 的线渲染在部分显卡/驱动可能与 `RENDERTYPE_LINES_SHADER` 有兼容差异；若异常，回退方案：去掉穿透线，仅保留 HUD 准星（仍满足「画个准星显示炮塔锁定」）喵。
- **相机俯仰锁 0**：玩家实体 xRot 仍会随鼠标累加，仅相机被 `ViewportEvent.ComputeCameraAngles` 强制水平；块高亮（黑线框）可能出现在炮塔上方，属轻微视觉残留喵。
- **传送与区块**：附身会把玩家实体传送到炮塔，服务端按玩家位置加载区块；若炮塔在超视距位置，可能短暂虚空/黑屏（区块加载延迟），一般 1 秒内恢复喵。
- **noPhysics 玩家**：附身期间玩家不碰撞、不窒息；但可能被部分爆炸/虚空判定波及，必要时后续加 `LivingHurtEvent` 附身期间免伤喵。
- **单机 vs 联机**：单机（内置服务端）`RightClickBlock` 服务端侧一次处理；`TurretPossessManager` 直接持有 `ServerPlayer` 引用（登出事件兜底清理），不依赖 `MinecraftServer.getServer()` 静态方法喵。
