# T12 核心背面消失（立方体单面渲染剔除）修复喵

## 目标喵

修核心 3×3×3 立方体从背面对一定视角会「消失（无渲染）」的问题：让整颗立方体 6 面双面可见，任何视角（含背面、贴脸、立方体内部视角）都渲染，且贴图正常、全亮、队伍染色层保留喵。

## 现象喵

T8c 后核心 base 层用 `RenderType.solid()` 画 3×3×3 立方体，从正面看正常，但从背面/贴脸等一定视角整颗立方体无渲染喵。

## 根因喵

1. `RenderType.solid()` 是**单面渲染**（背面剔除 CULL）。方块图集系渲染类型 `solid()`/`cutout()`/`cutoutMipped()`/`translucent()` 在 1.21.1 的 `CompositeState` 默认 `cullState=CULL`，**没有任何现成「方块图集 + 双面」类型**（已反编译字节码逐一验证：CUTOUT、TRANSLUCENT、translucentMovingBlock、tripwire 均不设 `setCullState(NO_CULL)`，继承 builder 默认 CULL）喵。
2. 核心立方体 3 格深、3 格高，玩家贴脸或走进视觉内部时，相机落在立方体体素内或呈背面绕序，朝向相机的面被剔除，整颗立方体便无渲染喵。
3. 队伍染色层用的 `RenderType.entityTranslucent` 本就 `NO_CULL`（双面），不受影响喵。

## 修复喵

改动 `src/main/java/com/blockdustry/client/CoreBlockEntityRenderer.java`喵：

1. 新增 import：`DefaultVertexFormat`、`VertexFormat`、`RenderStateShard`喵。
2. 新增静态字段 `CORE_BASE_NO_CULL`：用公开的 `RenderType.create(...)` 自建一个**方块图集 + 无 cull** 的渲染类型喵：

```java
// 双面方块渲染类型：方块图集贴图 + NO_CULL（关闭背面剔除），修核心立方体背面/贴脸视角消失喵
private static final RenderType CORE_BASE_NO_CULL = RenderType.create(
        "bd_core_base_no_cull",
        DefaultVertexFormat.BLOCK,
        VertexFormat.Mode.QUADS,
        1536, false, false,
        RenderType.CompositeState.builder()
                .setShaderState(RenderStateShard.RENDERTYPE_SOLID_SHADER)
                .setTextureState(RenderStateShard.BLOCK_SHEET_MIPPED)
                .setLightmapState(RenderStateShard.LIGHTMAP)
                .setCullState(RenderStateShard.NO_CULL)
                .createCompositeState(false));
```

- 保留 SOLID shader + BLOCK_SHEET_MIPPED + LIGHTMAP，与原来 `RenderType.solid()` 完全一致的视觉，仅把 cull 关掉，base 贴图（方块图集）不丢喵。
- BLOCK 顶点格式含 UV2(light)，quad 内 `setLight(LightTexture.FULL_BRIGHT)` 全亮行为不变；`setOverlay(NO_OVERLAY)`、`setNormal(...)` 照旧喵。
- 队伍染色层 `RenderType.entityTranslucent(TEX)` 不改（本就双面）喵。

3. base 层取 buffer 由 `buffer.getBuffer(RenderType.solid())` 改为 `buffer.getBuffer(CORE_BASE_NO_CULL)`，其余 6 个 quad 顶点不动喵。

## 验证喵

- `./gradlew compileJava` BUILD SUCCESSFUL（仅既存的 `TextureAtlas.LOCATION_BLOCKS` 弃用「注」，非本次引入）喵。
- 预期：核心 3×3×3 立方体从任何视角（正面、背面、贴脸、站到内部）都渲染，base 全亮不再黑，顶面队伍染色十字正常喵。

## 坑补充（已并入 docs/研究-渲染与模型坑.md §8）喵

- 方块图集系渲染类型 `solid/cutout/cutoutMipped/translucent` **全部默认开 CULL**，没有现成双面类型；BER 画大立方体要双面，需用 `RenderType.create` 自建「方块图集 + NO_CULL」类型（BLOCK 格式 + SOLID shader + BLOCK_SHEET_MIPPED + LIGHTMAP）喵。
- `RenderType.create` 与 `RenderStateShard.RENDERTYPE_SOLID_SHADER/BLOCK_SHEET_MIPPED/LIGHTMAP/NO_CULL` 均为 public，可直接调用（仓库 TurretPossessHandler 已有同款用法）喵。
