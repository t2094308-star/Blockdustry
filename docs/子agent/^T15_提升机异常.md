# T15 垂直提升机工作异常排查与修复喵

## 一、结论（TL;DR）喵

根因：**BER 渲染坐标单位错误**。`ElevatorBlockEntityRenderer` 里把像素当方块单位用，`PoseStack.translate` 期望的是「格」(1 block)，而代码传的是 `0.25 + p*15.5`（0.25→15.75，像素值），导致物品随 progress 被画到 **0.25~15.75 格之外**（几乎飞到塔顶上方 15 格高空），看起来「上移错乱 / 与传送带交互异常」喵。

修复：把像素换算成方块单位（除以 16），物品就回到提升机竖管内 0.0156→0.984 格正常上移喵。已修复并 `./gradlew compileJava` 通过喵。

## 二、排查过程喵

### 2.1 逻辑层（ElevatorBlockEntity）—— 未发现功能 bug 喵

逐项核对，**接收/上移/顶部交接逻辑全部正确**：

- `acceptItem`：同队判定 `getTeam().canInteract(source.getTeam())` OK；`directionOf(source)` 先判 `.above()→UP`（输出端，拒收），再扫水平四邻 → 侧收，再判 `.below()→DOWN` → 下收；`items[0]==null` 才收。与设计一致喵。
- `handleItem`：二次 accept 后 `items[0]=item; progress=0.001f`（格底起步）喵。
- `tickAnchor`：单槽 `progress += SPEED`，出口 `front=level.getBlockEntity(worldPosition.above())`，转 `BlockdustryItemSink`；可收上限 1.0，被堵 `NEXT_MAX_BLOCKED=0.95`；到 1.0 且上方 sink `acceptItem+handleItem` 成功 → 清空本格交接上方。与 Conveyor 头部交接同构（1 槽简化版）喵。
- `getPos()` 返回 `worldPosition`，`BlockdustryItemSource` 接口用法正确；顶部交接把 `this` 当 source 传给上方 sink，上方 Elevator 的 `directionOf` 判 `DOWN`（下方），Router/机器基类不查方向直接收 —— 全部通喵。

**交互验证（手工推演）**：
- 侧喂：传送带 facing 朝提升机 → 传送带 `front=pos.relative(facing)` 即提升机 → `acceptItem` 判水平邻居 → 收件，progress 0.001 上移喵。
- 竖叠接力：下节 `front=worldPosition.above()` 是上节 → 上节 `directionOf` 判 `DOWN` → 收件；同 tick 内无复制/丢失（槽满则下节限位 0.95 等待）喵。
- 顶端：交给上方 Router/机器（基类收件），Router `dumpItem` 水平吐出喵。

**已知限制（非本 bug，设计如此）**：
1. 提升机顶部**不能直接交给上方传送带**——`ConveyorBlockEntity.directionOf` 只扫水平四邻，`source.getPos()` 在 `.below()` 时返回 null 拒收（T14 已知限制 1）喵。
2. 提升机**底部只能靠侧喂**——基类 `dumpItem` 只扫水平四邻，Router/机器无法从下方喂提升机（T14 已知限制 2）喵。

### 2.3 渲染层（ElevatorBlockEntityRenderer）—— 根因就在这里喵

```java
// 修复前（错误）：
double y = 0.25 + p * 15.5; // 0.25 → 15.75 是「像素」，而 translate 要「格」
pose.translate(0.5, y, 0.5); // 物品最高被画到 +15.75 格（塔顶上方 15 格）喵
```

对照 `ConveyorBlockEntityRenderer`：传送带 `translate(0.5 + along, 0.25, 0.5 + along)`，y 固定 0.25 格、横向沿 1 格内移动，单位正确喵。提升机把 T14 注释里的「像素」数值直接塞进 `translate`，单位错了 16 倍喵。

## 三、修复喵

文件：`src/main/java/com/blockdustry/client/ElevatorBlockEntityRenderer.java`

```java
// 像素转方块单位：pose.translate 用「格」(1/16) 而非像素，直接写 0.25+15.5 会把物品画到天上 15 格喵
double y = (0.25 + p * 15.5) / 16.0; // 格底 0.0156 → 格顶 0.984（block 单位）喵
```

- 格底 `p=0.001`：y≈0.0157 格（紧贴格底，与侧喂入手一致）喵。
- 格顶 `p=1.0`：y≈0.984 格（交接瞬间即清空，视觉不会穿进上方格）喵。
- 被堵 `p=0.95`：y≈0.937 格（停在竖管上沿，不穿模）喵。
