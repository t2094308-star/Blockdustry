# T22 科技树解锁指令阶段产出喵

## 目标喵
新增 debug 指令「一键解锁所有科技」：管理员执行后服务端解锁全部节点并广播同步客户端喵。

## 一、实现内容喵
| 文件 | 改动喵 |
|---|---|
| `src/main/java/com/blockdustry/research/ResearchManager.java` | 新增 `public static int unlockAll(ServerLevel)`：遍历 `ResearchTree.allNodes()`，跳过默认解锁，对未解锁节点 `data.unlock(id)` 并计数，返回新解锁数喵 |
| `src/main/java/com/blockdustry/research/ResearchCommands.java` | 新增（独立新文件）：`@EventBusSubscriber(modid)` 自注册 `RegisterCommandsEvent`，注册 `/blockdustry research unlockall`（requires 权限 2），执行时 `ResearchManager.unlockAll(level)` + `PacketDistributor.sendToAllPlayers(buildState(level))` + 源回显「已解锁 N 个科技节点」喵 |

- **不碰共享 `BlockdustryCommands.java`**：`ResearchCommands` 独立 `@EventBusSubscriber` 自注册，Brigadier 同名 `/blockdustry` literal 子树自动合并到既有根（既有 `/blockdustry team/tick/building` 不受影响）喵。
- 未改动科技树 UI / 消耗逻辑（Mindustry 移植保持原样）喵。

## 二、注册说明喵
- 无需手动挂载：`@EventBusSubscriber` 随 mod jar 自动扫描注册喵。
- 权限：`s.hasPermission(2)`（OP/单人作弊可用，与既有 `/blockdustry` 一致）喵。
- 用法：管理员执行 `/blockdustry research unlockall` → 服务端解锁所有非默认节点 → 全量状态广播 → 客户端树形 UI 全部变绿、连线变绿、可自由放置喵。

## 三、编译喵
- `./gradlew compileJava` **BUILD SUCCESSFUL**（仅既有 deprecation 警告）喵。

## 占用与交接喵
- 占用文件（写）：ResearchManager.java、ResearchCommands.java、docs/子agent/^T22_科技树解锁指令.md、任务登记 T22_科技树解锁指令.md 喵。
- 交接给：主会话（runClient 实测：进服后 `/blockdustry research unlockall`，J 开树看全解锁 + 可放置全部建筑）喵。
- 风险/待人工排查：无（指令只服务端权威解锁 + 广播，与既有命令模式一致）喵。
