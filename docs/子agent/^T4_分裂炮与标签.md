# T4 分裂炮与目标标签 阶段产出喵

## 目标喵
为 Blockdustry (NeoForge 1.21.1) 迁移 Mindustry「分裂」对空炮（Scatter）并实现「目标标签」索敌系统：炮台按「对地/对空」过滤索敌，单位为「陆/空/海」打标喵。

## 结论/产出喵

### 1. 目标标签系统（新文件）喵
- 新文件 `src/main/java/com/blockdustry/entities/TargetType.java`（包名用现有 `entities`，与工程一致，任务描述里的 `entity/` 为笔误）喵
  - 枚举 `GROUND / AIR / SEA` 喵
  - `TargetType.canTarget(unit)`：炮台过滤语义——`GROUND` 炮不锁 `AIR`（陆+海都打）；`AIR` 炮只打 `AIR`；`SEA` 炮只打 `SEA`（预留）喵
  - 静态 `TargetType.of(LivingEntity)`：Blockdustry 单位取各自 `getTargetType()`，其余活体兜底 `GROUND` 喵
- 改 `src/main/java/com/blockdustry/entities/DaggerUnitEntity.java`：新增 `public TargetType getTargetType()` 返回 `GROUND`（参考 `setBlockdustryTeam` 模式）喵

### 2. 炮台索敌过滤（改共享炮塔骨架）喵
- 改 `src/main/java/com/blockdustry/building/TurretBlockEntity.java`：
  - 将原 `static final` 炮塔常量改为 `protected` 实例字段（`reload/range/shootY/spread/bulletSpeed/bulletDamage/rotateSpeedDeg`），子类可覆盖喵
  - 新增 `protected TargetType targetFilter = TargetType.GROUND;`（duo=对地）与 `protected boolean canTarget(LivingEntity)` 喵
  - `nearestLiving` 增加标签过滤（敌对 + `canTarget`）；`nearestBuilding` 对 `AIR` 过滤返回 `null`（对空炮不锁地面建筑，忠于 `targetGround=false`）喵
  - 索敌/开火相关方法改为 `protected`，供 Scatter 复用（`turnToward/moveToward/sync/fireAt/predict/nearestLiving/nearestBuilding/isEnemyOf`）喵
  - 命中逻辑不改：duo 的普通炮弹沿弹道命中「空」单位仍造成伤害（满足"对地炮不主动锁空、但同线命中仍有效"）喵

### 3. 分裂炮（新文件）喵
- 新文件 `src/main/java/com/blockdustry/building/ScatterBlockEntity.java`（继承 TurretBlockEntity 骨架）喵
  - 参数（忠于 Mindustry `Blocks.java` 的 scatter）：`reload=18`、`range=27.5`（220/8）、`bulletSpeed=1.3`、`bulletDamage=27`、`rotateSpeedDeg=15`、`targetFilter=AIR` 喵
  - 双连射：`shoot.shots=2`、`shotDelay=5`（`shotsFired` 计数，打满 2 发进入完整装填）喵
  - 大散布（`inaccuracy=17°`，散布量为 duo 的 3 倍），发射 `FlakBulletEntity` 喵
- 新文件 `src/main/java/com/blockdustry/entities/FlakBulletEntity.java`（flak 霰弹，忠于 `FlakBulletType.java`）喵
  - 只对「空」标签敌对单位生效（`collidesGround=false` 语义，不伤地面单位与建筑）喵
  - 近炸引信：进入 `explodeRange` 的敌对空单位 → 延时 `PRIME_DELAY=5` tick 引爆；直接碰撞/寿命耗尽也引爆喵
  - 引爆对 `splashRadius` 内敌对空单位造成 `splashDamage`（lead ammo 折算：40 / 2 格 / 近炸 2 格），并播爆炸粒子喵
- 新文件 `src/main/java/com/blockdustry/client/ScatterBlockEntityRenderer.java`（Mindustry DrawTurret "-mid" 单转盘 + 整体后坐力）喵
  - 贴图暂复用 `turret_top.png`（主会话可换 scatter 专属贴图）喵

### 4. 编译验证喵
- `./gradlew compileJava`：还原注册桩后仅剩 2 个预期缺失符号（`SCATTER_ENTITY`、`FLAK`，属主会话注册范围）喵
- 临时加入注册桩后完整编译通过（0 错误），已还原注册文件（git 无残留 diff）喵

- 风险/待人工排查:
  - 目前只有 dagger（GROUND），**scatter 在游戏内无空目标可锁、不会开火**。要实测需先造一个 AIR 标签单位（新实体类 `getTargetType()` 返回 `AIR`，或在 `TargetType.of` 加测试分支）喵

  - flak 溅射只伤空，对地无效——若后期想"溅射误伤地面"，需在 `FlakBulletEntity.explode()` 放宽 `isEnemyAir` 判定喵
