# T6 矿机叶片 阶段产出喵

## 目标喵
深度排查 Blockdustry 钻机（drill）2×2 顶部 BER 叠画的旋转叶片贴图「缺失/显示异常」问题，定位根因并给出修复方案喵。

## 结论一句话喵
**贴图来源正确、资源已就位、几何/遮挡/纹理加载均无问题；唯一与全项目其它渲染器相悖的点是 `DrillBlockEntityRenderer` 透传 BER 的 `light`/`overlay` 而非像 `Turret`/`CombustionGenerator`/`PowerNode` 那样硬编码 `setLight(0xF000F0)`+`NO_OVERLAY`。** entityCutout 在白天地表只拿到 (block=0, sky=15) 的暗光贴图（约满亮 4~5 成），深棕金属叶片被压成近黑 → 用户观感「叶片缺失/看不见」喵。修复就是把该渲染器的 `setLight(light)`/`setOverlay(overlay)` 改成 `0xF000F0`/`NO_OVERLAY` 喵。

## 3. 根因（与炮管黑同一坑）喵

`BlockEntityRenderDispatcher` 传入的 `light = LevelRenderer.getLightColor(pos) = sky<<20 | block<<4`。白天地表方块 **sky=15、block=0** → `0xF00000`。`entityCutout` shader 按 `UV2/16` 采 16×16 光贴图 **(block=0, sky=15)** 那一格，`LightTexture.updateLightTexture` 用 `getSkyDarken≈0.24` 把天光压到约满亮 **4~5 成**（灰蓝 ~(115,115,161)）喵。

钻机叶片是深棕金属 (178,135,104)，× 暗光 ≈ (80,61,47) **近黑**，叠加在明亮方块顶上时视觉上「看不见/缺失」喵。在洞穴/夜晚 sky=0 时 light≈0，叶片会**彻底消失**，与用户「缺失」描述完全吻合喵。

这坑全项目早已踩过并在 `docs/研究-炮管黑.md` 白纸黑字记录：炮塔炮管正是因此从「暗」变成「黑」，修复后改硬编码 FULL_BRIGHT 才正常；`Turret` 是当时「漏改」的，而 **drill 至今仍是唯一继续透传 light 的方块实体渲染器**喵。

**排除项**（逐条证伪）：不是贴图颜色/纯透明；不是贴图加载失败（日志无 Failed to load texture）；不是 overlay（dispatcher 传的就是 NO_OVERLAY）；不是法线/方向光（light.glsl 对 +Y 法线全亮）；不是几何遮挡/z-fighting（y 高 0.02）；不是 CULL（绕序正确）；不是 2×2 中心偏移错误喵。

## 4. 修复方案（渲染修正，改动最小）喵

改 `src/main/java/com/blockdustry/client/DrillBlockEntityRenderer.java`，把 4 个顶点的 `setLight(light).setOverlay(overlay)` 换成 `setLight(0xF000F0).setOverlay(OverlayTexture.NO_OVERLAY)`，对齐已验证正常的 Turret/CombustionGenerator 喵：

```java
import net.minecraft.client.renderer.texture.OverlayTexture; // 新增喵
// （LightTexture.FULL_BRIGHT == 0xF000F0，直接用字面量贴合项目风格亦可喵）

vc.addVertex(matrix, -1f, 0f, -1f).setUv(0f, 0f).setColor(255, 255, 255, 255).setLight(0xF000F0).setOverlay(OverlayTexture.NO_OVERLAY).setNormal(0f, 1f, 0f);
vc.addVertex(matrix, -1f, 0f, 1f).setUv(0f, 1f).setColor(255, 255, 255, 255).setLight(0xF000F0).setOverlay(OverlayTexture.NO_OVERLAY).setNormal(0f, 1f, 0f);
vc.addVertex(matrix, 1f, 0f, 1f).setUv(1f, 1f).setColor(255, 255, 255, 255).setLight(0xF000F0).setOverlay(OverlayTexture.NO_OVERLAY).setNormal(0f, 1f, 0f);
vc.addVertex(matrix, 1f, 0f, -1f).setUv(1f, 0f).setColor(255, 255, 255, 255).setLight(0xF000F0).setOverlay(OverlayTexture.NO_OVERLAY).setNormal(0f, 1f, 0f);
```

- `0xF000F0`(=LightTexture.FULL_BRIGHT) 采光贴图 (15,15) 纯白格，叶片恢复真实金属棕，亮顶面上清晰可见喵。
- 若想保留夜晚变暗的环境光玩法，可改用保底：`Math.max(light, LightTexture.FULL_BLOCK | (light & LightTexture.FULL_SKY))`，但最直接验证就是 FULL_BRIGHT 喵。
- 验证：改完需重跑 `processResources`/`runClient`（dev 从 `build/resources/main` 读资源）喵。
- 建议顺手把 `render()` 的 `light`/`overlay` 形参改为忽略（`_light`/`_overlay`）避免误用喵。

## 5. 疑点/待人工排查清单喵
1. 若改 FULL_BRIGHT 后叶片仍不可见 → 在游戏内按 F3 看是否有 shader 报错，并检查 `run/client/logs/latest.log` 新增的 `Failed to load texture` 喵。
2. 若叶片出现但**不转** → 检查 `gameTime`/`partialTick`（应随游戏 tick 增长）喵。
3. 若叶片**位置偏移**/出现 4 份叠影 → 客户端锚点未同步（NBT `bd_anchor_*` 丢失导致 4 格都 `isAnchor()`），检查 `setAnchor` 的 `sendBlockUpdated`/`getUpdateTag` 链路喵。
4. 若从特定角度叶片与顶面 z-fighting → 把 y 从 `1.02` 提到 `1.03` 喵。
5. 若 FULL_BRIGHT 后叶片过亮刺眼 → 可降为 `Math.max(light, 0x00F0F0)` 之类保底，但默认建议全亮贴近 Mindustry 原版观感喵。
