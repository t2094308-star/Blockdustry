# T12 附身俯仰 阶段产出喵

## 目标喵
修复「附身炮塔后只能左右旋转（不能上下）」：放开相机俯仰（鼠标上下能自由看），并顺带让弹道也带俯仰（玩家视线方向开火），炮塔仍由 yRot 驱动水平转向喵。

## 结论/产出喵
- **放开相机俯仰**：`ViewportEvent.ComputeCameraAngles` 不再 `setPitch(0)`，只保留 `setRoll(0)` 防侧倾；相机 pitch 跟随玩家 xRot（MC 鼠标上下默认改 xRot），附身即可上下看喵。
- **俯仰弹道（低成本扩展）**：控制包从 `(aimYaw, fire)` 扩为 `(aimYaw, aimPitch, fire)`；`aimPitch = 玩家 xRot`（向下看为正），服务端透传给 `TurretBlockEntity`，手动开火方向改为含 y 分量的 3D 视线向量喵。
- **穿透视野瞄准线 3D 化**：红线改为从炮口沿玩家视线（含俯仰）到射程末端，与弹道一致，不再水平喵。
- 既有功能（穿透视野/瞄准线/射程圈、shift 退出、HUD 准星提示、开火节流）保持不变喵。

## 角度约定喵
- 水平：`aimYaw = 180 - 玩家 yRot`（沿用 T5）喵。
- 俯仰：`aimPitch = 玩家 xRot`（MC 中向下看为正），弹道 `dir = (-sin(yaw)·cos(pitch), -sin(pitch), -cos(yaw)·cos(pitch))`，pitch>0 时 dir.y<0 朝下，与玩家视线一致喵。
- 兼容性：pitch=0 时公式退化为 T5 的 `(-sin yaw, 0, -cos yaw)`，行为不变喵。

## 风险/待人工排查喵
- **炮管渲染不俯仰**：`TurretBlockEntityRenderer` 仍只按 `aimYaw` 水平转，弹道带俯仰但炮管不抬，视觉上「炮口没抬弹却斜飞」。本轮按最小实现不改渲染；若后续要做「炮管真的抬」，需给 BER 加 pitch 旋转 + 同步字段（附身包或快照）喵。
- **pitch 无软限位**：直接透传玩家 xRot（MC 已 clamp ±90°），俯仰弹道可近垂直；若想模拟 Mindustry 炮塔俯仰限位（如 -20°~80°），可在服务端 `setManualAim` 或客户端发送前 clamp 喵。
- **节流灵敏度**：pitch 变化阈值 1°，与 yaw 一致；快速甩视角可能偶尔丢 1~2 tick，靠 `gt-lastControlSend>=2` 保底兜住喵。
- **伸手怪**：`fireAt` 的横偏 `perp = (-dir.z, 0, dir.x)` 恒垂直于 dir（含 y 分量），双管横偏与炮口前伸仍正常喵。
