# T18 创造栏分类（Mindustry Category 化）喵

## 目标喵
把 Blockdustry 的单个「方块工业」创造 tab 拆成多个，按 Mindustry 原版 Category 分类规则归入各功能 tab 喵。

## 分类表（Mindustry Category → 本 mod tab → 物品）喵

| 本 mod tab（lang key） | 标题 zh/en | Mindustry Category | 物品/方块 |
|---|---|---|---|
| `crafting` | 锻造 / Crafting | crafting + production | drill（机械钻头）、graphite_press（石墨压缩机） |
| `distribution` | 物流 / Distribution | distribution | conveyor（传送带）、router（路由器）、elevator（垂直提升机） |
| `power` | 电力 / Power | power | power_node（电力节点）、combustion_generator（燃烧发电机）、battery（电池）、power_source（电力源，Mindustry 为 sandboxOnly 但归 power） |
| `storage` | 存储 / Storage | effect（core 在 Mindustry 归 effect） | core（核心，3×3 存储/重生） |
| `defense` | 防御 / Defense | turret | turret（双管 duo）、scatter（分裂）、fuse（熔毁）、arc（电弧） |
| `units` | 单位 / Units | units | unit_factory（地面单位工厂） |
| `items` | 物品 / Items | （Mindustry 无此 Category，按物品归类） | graphite、silicon、lead（MC 煤已有故不放） |
| `debug` | 调试 / Debug | sandboxOnly（item_source 原 Category.distribution 但 BuildVisibility.sandboxOnly） | item_source（物品源）、debug_stick（队伍调试棒） |

注：Mindustry `Category` 枚举（`D:\Blockdustry\Mindustry\core\src\mindustry\type\Category.java`）：turret / production / distribution / liquid / power / defense / crafting / units / effect / logic 喵。
对应方块在 `Blocks.java` 里的实际归类：mechanicalDrill=`Category.production`、graphitePress=`Category.crafting`、conveyor/router=`Category.distribution`、powerNode/combustionGenerator/battery/powerSource=`Category.power`、coreShard=`Category.effect`、duo/scatter/arc/fuse=`Category.turret`、groundFactory=`Category.units`、itemSource=`Category.distribution`+`sandboxOnly`。本表把 production+crafting 合为「锻造」tab，把 effect 中的 core 放「存储」tab，sandbox 块放「调试」tab 喵。

## 改动喵

### `src/main/java/com/blockdustry/building/BlockdustryBlocks.java`
- 删除单 `TAB`（`itemGroup.blockdustry`），改为 8 个 `CREATIVE_TABS.register(...)`：`CRAFTING_TAB` / `DISTRIBUTION_TAB` / `POWER_TAB` / `STORAGE_TAB` / `DEFENSE_TAB` / `UNITS_TAB` / `ITEMS_TAB` / `DEBUG_TAB`，各 tab `displayItems` 只 accept 对应分类物品喵。
- 跨类物品引用：`ElevatorBlocks.ELEVATOR_ITEM`（物流）、`FuseArcRegistrar.FUSE_ITEM`/`ARC_ITEM`（防御）、`DEBUG_STICK`（调试）、`ITEM_SOURCE_ITEM`（调试）喵。
- 每个物品只归一个 tab，无重复 accept 喵。

### lang
- `src/main/resources/assets/blockdustry/lang/zh_cn.json`
- `src/main/resources/assets/blockdustry/lang/en_us.json`
- 移除旧 `itemGroup.blockdustry`，新增 `itemGroup.blockdustry.{crafting,distribution,power,storage,defense,units,items,debug}` 对应中英文标题喵。

## 验证喵
- `./gradlew compileJava` → BUILD SUCCESSFUL（8 个 tab 字段经 javap 确认已编译进 `BlockdustryBlocks.class`，旧 `TAB` 已移除）喵。
- `./gradlew processResources` → BUILD SUCCESSFUL；两个 lang JSON 校验通过喵。
- 期间一次编译报 6 错在 `ResearchClientCache.java`/`ResearchScreen.java`（并发 T17 任务编辑中转态），现已恢复，非本任务引入喵。

## 占用与交接喵
- 占用文件（已写）：`building/BlockdustryBlocks.java`、`lang/zh_cn.json`、`lang/en_us.json`、本文档喵。
- 交接给：主会话。需确认 `FuseArcRegistrar` 与 `ElevatorBlocks` 的 `register(bus)` 已挂载（`Blockdustry.java` 构造器已有，无需改动）喵。
- 风险：创造栏 tab 顺序为注册顺序（锻造→物流→电力→存储→防御→单位→物品→调试）；若想调序可改注册先后喵。
