## 三、本次新增修复：电梯顶直连正上方传送带喵

### 3.1 原缺陷喵

`ConveyorBlockEntity.directionOf` 只扫水平四邻 + 坡道背向上下格；源在**正下方**（Elevator 顶格 `front=pos.above()`）返回 null → `acceptItem` 拒收 → 顶格物品卡 0.95 永不交接（T14 已知限制 1）喵。

### 3.2 修复喵

文件：`src/main/java/com/blockdustry/building/ConveyorBlockEntity.java`

```java
// 提升机顶格交接（T18）：源是 Elevator 且直接位于本格正下方 → 视为尾部进料，沿本带朝向运走喵
if (source instanceof ElevatorBlockEntity && worldPosition.below().equals(source.getPos())) {
    return getFacing().getOpposite();
}
```

- `entry = getFacing().getOpposite()` → 走正后尾插分支：尾部 `[0, ITEM_SPACE)` 无物 + 有空槽即收；`handleItem` 插到最低 progress 空槽、progress=0.001，沿带向流动喵。
- 影响面极小：仅当「源是 Elevator 且正好在本格正下方」才触发；平面/坡道/侧插/尾插行为完全不变；其他建筑源（drill/router 等）不触发喵。
- 字节码确认：`instanceof com/blockdustry/building/ElevatorBlockEntity` + `BlockPos.below()` 已编译进 `ConveyorBlockEntity.class` 喵。

### 3.3 仍属设计约束（非 bug）喵

- **传送带放塔顶侧面但朝向「正对着」电梯**：`directionOf` 判该向为传送带输出端 `getFacing()` → 拒收（传送带只在背向/侧向收件，输出端永远是出口）。这是传送带语义，非电梯缺陷；正确摆法是传送带朝向**远离/侧向**电梯喵。
- **多格建筑 dumpItem 只扫水平四邻**：Router/机器无法从下方喂电梯底（T14 已知限制 2，本次未动）喵。
