# T14 火焰炮 fuse 与电弧炮 arc 迁移文档喵

> 迁移 Mindustry 的 **fuse（熔毁/火系霰弹炮）** 与 **arc（电弧/电系闪电炮）** 到本 mod 喵。
> 任务产物：9 个新 Java 文件 + 贴图/模型/blockstate 资源，均独立新文件，未触碰共享注册文件（BlockdustryBlocks/BlockdustryEntities/BlockdustryClient）喵。
> 主会话只需按「注册清单」一节接线即可跑通喵。

## 3. 主会话注册清单（完成这几步即可跑通）喵

1. **挂载注册**：`Blockdustry.java` 构造器加一行喵
   ```java
   FuseArcRegistrar.register(modEventBus);   // import com.blockdustry.building.FuseArcRegistrar;
   ```
2. **注册渲染器**：`BlockdustryClient.java` 的 `registerRenderers(EntityRenderersEvent.RegisterRenderers)` 加 4 行喵
   ```java
   event.registerBlockEntityRenderer(FuseArcRegistrar.FUSE_ENTITY.get(), FuseBlockEntityRenderer::new);
   event.registerBlockEntityRenderer(FuseArcRegistrar.ARC_ENTITY.get(), ArcBlockEntityRenderer::new);
   event.registerEntityRenderer(FuseArcRegistrar.FIRE_BULLET.get(), FireBulletRenderer::new);
   event.registerEntityRenderer(FuseArcRegistrar.ARC_BEAM.get(), ArcBeamRenderer::new);
   ```
3. **创造栏**：`BlockdustryBlocks.java` 的 TAB `displayItems` 加 `output.accept(FUSE_ITEM); output.accept(ARC_ITEM);`（可选但建议）喵
4. **lang**：`en_us.json` 加 `"block.blockdustry.fuse": "Fuse"`、`"block.blockdustry.arc": "Arc"`；`zh_cn.json` 加 `"block.blockdustry.fuse": "熔毁"`、`"block.blockdustry.arc": "电弧"` 喵
5. **预存编译错误（非本任务引入）**：`power/PowerSourceBlockEntity.java:29` 引用 `BlockdustryBlocks.POWER_SOURCE_ENTITY` 但 BlockdustryBlocks 未注册该符号，导致整个 `compileJava` 失败。需主会话补注册 `POWER_SOURCE`（方块/物品/BE）或修正该引用，否则全工程编译不过喵
6. **实体属性**：FireBulletEntity / ArcBeamEntity 均为 Projectile 子类，无需注册 attributes 喵

## 4. 风险与注意事项喵

1. **转盘朝向校准**：fuse/arc 渲染沿用 duo/scatter 同一 `turnToward(atan2(-dx,-dz))` + `rotationDegrees(yaw)` 校准（贴图"前"= 图像上方 = 世界 -Z）。已用像素分析确认 fuse.png 三管朝图像上方、arc.png 为对称线圈，理论上与 duo 一致；若实机炮管偏 90°/180°，参考 `docs/研究-炮塔动画.md` 微调（可能需在渲染器加固定旋转偏移）喵
2. **`EntityDataSerializers.DOUBLE` 在本 MC 1.21.1 不存在**（只有 FLOAT/INT 等）：ArcBeamEntity 终点已改用 FLOAT 三轴，精度足够（位置 ±50 格内）喵
3. **fuse 全锁语义**：fuse 实际 targetAir+targetGround=true，通过覆写 `canTarget()` 返回 true 实现；但基类 `targetFilter` 字段仍显示 GROUND（仅 Jade/调试展示偏差，不影响索敌）喵
4. **弹药选择**：fuse 默认用 titanium 弹药 damage=66（thorium 105 未启用）；如需换弹需改 `bulletDamage` 喵
5. **arc 闪电简化**：非 Mindustry 逐段链式闪电，改为「直线束 + 锯齿视觉 + 线段范围判定（半径 1.5 格）」；建筑伤害 ×0.25 已在 ArcBeamEntity 内结算喵
6. **fuse 弹速折中**：原作 Shrapnel 是 hitscan（speed=0, lifetime=10），MC 折中为高速弹丸 bulletSpeed=1.8、寿命 range/speed，视觉近似瞬击喵
7. **compileJava 验证**：本任务 9 个新 Java 文件在「临时修补 POWER_SOURCE 后」编译全通过（BUILD SUCCESSFUL）；恢复原样后编译仍会被预存 POWER_SOURCE 错误卡住，非本任务文件问题喵
8. **资源完整性**：贴图/模型/blockstate/lang 均已备齐（lang 未动，留给主会话按上面清单加）；fuse 基座用 Mindustry 通用 block-3.png，与原作 base 一致喵
