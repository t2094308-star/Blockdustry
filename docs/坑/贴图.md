# 坑：贴图资源 / 比例 / 命名 喵

## 1. 命名规范（用户约定）喵
- 面编号：顶面=1 / 侧面=2 / 底面=3；命名 `{名称}_{面}_{标准|高清}_{备注}.png` 喵
- **64×64 为标准、512+ 为高清**——64×64 别标「高清」喵
- 不要用奇怪的英文缩写，过两天看不懂喵

## 2. 侧面贴图比例 喵
- 2×2 建筑侧面整面 = 2 格宽 × 1 格高（2:1）。若模型每格是独立方形面片（16×16 face + uv 全图），贴图保持**方形** + 左右无缝拼合即呈 2:1；若贴图本身 1:2（如 1024×512）需切半给左右格分别引用喵
- **坑**：侧面贴图内容必须是**侧面视角**（深色底座外壳/金属），不能拿顶面贴图局部当侧面（见 `机器侧面贴图.md`）喵

## 3. 透明底 喵
- 透明底 RGBA 贴图必须用 entityCutout/entityTranslucent 渲染；方块 solid 渲染透明区变黑（scatter_base 曾透明底 solid 渲染变黑）喵
- 自绘贴图（PIL）输出方形全不透明（alpha 255）喵

## 4. 高清压缩 喵
- 高清（512+）自绘后再压缩 64×64（Lanczos）应用，风格稳定清晰；高清版备份到 `像素图片绘制尝试/` 按命名规范存档喵
