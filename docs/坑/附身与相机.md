# 坑：附身 / 相机 / 视角 / freecam 喵

## 1. 相机黑屏（视角在方块内部）喵
- 附身把玩家传送到炮塔**方块内部**，相机被实体方块遮挡 → 黑屏喵
- 修复：把玩家传送到炮塔**正上方干净空气位**（向上扫格找脚底+头顶皆空），保持「玩家在炮塔处」语义，穿透视野不受影响喵

## 2. shift 退出不生效（切换潜行）喵
- 裸按键 `mc.options.keyShift.isDown()` 在「切换潜行」模式下只按一下为真，连按计数累计不到喵
- 修复：`mc.player.isShiftKeyDown() || mc.options.keyShift.isDown()` 兼容切换潜行喵

## 3. NeoForge 事件不能改相机位置 喵
- `ViewportEvent.ComputeCameraAngles` 只改角度（且 1.21 早期 pitch/yaw 有 bug），**不能改相机位置/渲染中心**喵
- 上帝视角/灵魂出窍改相机位置必须走 `Minecraft.setCameraEntity()`（假相机实体）+ mixin（`Entity.turn()` 重定向、`LocalPlayer.input` 空操作、区块 `markChunksForRebuild`）喵
- 附身俯仰：`ComputeCameraAngles` 里可 `setRoll(0)` 锁翻转但别 `setPitch(0)`（会锁死上下视角）喵

## 4. 穿透视野/瞄准线 喵
- `RenderLevelStageEvent` **无 `getMultiBufferSource`**：改用 `Minecraft.renderBuffers().bufferSource()` + `endBatch(自定义RT)` 按类型刷新喵
- 玩家可见的瞄准线/射程圈别一直显示（用户觉得奇怪）；若要保留，开火瞬间短暂显示或极简（HUD 准星即可）喵
