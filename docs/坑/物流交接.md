# 坑：物流交接（物品传递 / directionOf / dumpItem / 顶面卸货层）喵

> 主题：建筑间物品交接、`directionOf` 收件方向判定、`dumpItem`/`dumpItemTop` 卸货范围与层高喵

## 1. Conveyor 的 directionOf 只认水平 + 正下方，不认斜向/坡道背向喵

- `ConveyorBlockEntity.directionOf(source)` 只扫**水平四邻**，再判**正下方源**；源在**正上方/斜下方**等不识别位置 → 返回 null → `acceptItem` 拒收喵。
- **修复模式（T18/T19）**：在 `directionOf` 末尾增补：
  ```java
  if (worldPosition.below().equals(source.getPos())) {
      return getFacing().getOpposite(); // 视为尾部进料，沿带向运走喵
  }
  ```
  - 接受**任意源**直接在本格正下方（电梯垂直交接的源=电梯 BE；电梯顶面四邻卸货的源=`TopSource`，getPos 定位在候选格正下方）喵。
  - 安全：全仓只有提升机向上推物品；Router/物品源/钻机 `dumpItem` 只扫水平四邻，不会把物品推给正上方传送带喵。
- 注意：传送带**坡道（UP/DOWN）已被并行任务 `^T19_删除爬坡回滚.md` 移除**，本坑不再适用坡道分支喵。

## 2. 传送带输出端永不收件喵

- `acceptItem` 里 `entry == getFacing()`（源在传送带**正前方**）→ 拒收（那是输出端）喵。
- **坑**：想用传送带在提升机塔顶接货，传送带朝向若**正对着**电梯（像底部喂料那样朝塔摆）→ 提升机甩不过去（传送带把它当输出端拒收）喵。正确摆法：传送带朝向**远离/侧向**电梯，让电梯位于其背向或侧向（正下方时无朝向限制，尾部进料）喵。

## 3. 卸货层高：dumpItem（自身 Y） vs dumpItemTop（Y+1）喵

- `BlockdustryBuildingEntity.dumpItem(Item)` 以**自身 Y 层**扫「全占地四邻域」的水平邻居，不向上/向下卸货喵。
- **坑（T19）**：提升机顶格兜底若用 `dumpItem`，物品视觉已顶到本格上沿（Y+1），却水平吐给**同 Y 层**的传送带 → 看起来「输出回落回输入端」喵。
- **修复**：提升机用 `ElevatorBlockEntity.dumpItemTop(Item)`——扫 **`worldPosition.above()`（Y+1 层）** 的水平四邻，源用 `TopSource(p.below())`（getPos 返回候选格正下方），配合 conveyor「正下方源」判定收件，输出保持在提升后的一层高喵。
- 通用教训：**卸货目标层 = 物品所在/输出层**，不要默认用方块自身层；涉及垂直传输的建筑要显式选对 Y 喵。

## 4. Mindustry 语义参考喵

- 原版 Mindustry：Elevator 顶部输出只向上，接水平带要靠 Router/分拣器中转；传送带本身水平不可堆叠喵。
- 本 mod 增强：提升机顶**正上方直连传送带**（T18）与 **Y+1 顶面四邻卸货**（T19）均可运出，无需 Router 中转喵。
