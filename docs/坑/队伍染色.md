# 坑：队伍染色 / 队伍数据同步 喵

## 1. 按队伍染色的实现 喵
- 叠画 team 层贴图（`RenderType.entityTranslucent`），顶点 setColor 用 `BlockdustryTeam.getColor()` ARGB（Mindustry 原作色：derelict #6f6f6f/sharded #5b7cfa/crux #cc4f4f/malis #7b5b9e/green #49d13c/blue #59cbe8/neoplastic #f2a7a0）喵
- 队伍数据需经 BE NBT（`bd_team`）同步到客户端，否则客户端恒 DERELICT 无色喵

## 2. 染色层 UV 别裁到透明角 喵
- core_team 队伍色贴图呈**十字形**（N/W/C/E/S 实心、四角透明），渲染器若把 UV 裁到角落会采到全透明区 → 染色层完全不可见；应整张铺（锚点格画整张 3×3 平面）喵

## 3. 玩家默认队伍 喵
- 新玩家实体队伍默认 DERELICT，放置建筑继承 DERELICT → 共享池/染色全归属 DERELICT 喵
- `TeamInitHandler`：玩家登录时 DERELICT 赋默认 SHARDED；查询侧 DERELICT 兜底回退 SHARDED 喵
- `BlockdustryTeams.setTeam` 改队伍后须 `sendBlockUpdated`，否则 Jade/HUD 不即时刷新喵
