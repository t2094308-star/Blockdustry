# 坑：炮弹 / 实体 / 伤害 喵

## 1. 炮弹卡顿根因（客户端不自模拟）喵
- 炮弹只在服务端 `move()`，客户端位置靠服务端位置包（updateInterval 默认 3 tick 一发 ≈ 6.7Hz）阶梯跳变 + 客户端 `xOld==getX()` 插值失效 → 瞬移卡顿喵
- 修复：客户端也 `move()`（2 参构造设 `noPhysics=true` 避免撞方块）+ 注册 `.updateInterval(1)` 喵

## 2. 实体注册与构造 喵
- `EntityType.Builder.of` 泛型推断失败用显式 `<T>of`；实体构造参数用精确 `EntityType<T>` 喵
- 注册 lambda 勿引用自身 `X_ENTITY.get()`（初始化自引用）；实体跨包继承须 import 基类喵
- 不同实体类型**不能共用一个 `EntityRenderer<T>`**（泛型不匹配），各实体需自己的渲染器喵

## 3. 伤害与装甲 喵
- Mindustry 装甲固定减伤：`最终伤害 = max(1, 原始 - 装甲)`；炮弹命中活体/建筑前先按装甲折算（`BlockdustryArmor`）喵
- `BlockHealthApi.damage` 无装甲参数，调用前自行折算；血量 per-pos 存 ServerLevel attachment 喵

## 4. 索敌与标签 喵
- 炮台索敌用 `BlockdustryTeams.isHostile`（DERELICT 攻击者打所有非 DERELICT，DERELICT 目标永不被攻击）喵
- 对地/对空标签 `TargetType`：对地炮不锁 AIR 目标、对空炮只锁 AIR（且不锁地面建筑）喵
- 炮弹命中活体目前**无队伍敌对过滤**（友军会被误伤，待办）喵
