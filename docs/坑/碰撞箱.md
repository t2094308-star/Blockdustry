# 坑：碰撞箱 / 多格 AABB 喵

## 1. 多格建筑整组 AABB 修复范式 喵
- 覆写 `getShape` 返回整组包围盒：`Block.box(-dx*16,0,-dz*16,(size-dx)*16,height*16,(size-dz)*16)`（dx/dz 从 blockstate corner 反推，2×2 四象限/3×3 九宫格），每格返回覆盖整组的 AABB，世界坐标重合为大实心碰撞体喵
- 视觉高于占地时 `height` 要 >1（核心传 3）喵
- `getShape` 与 `getCollisionShape` 都要一致（getCollisionShape 默认委托 getShape，若只改一个会不一致）喵

## 2. MC 碰撞求解器只扫「实体 AABB + 四周各 1 格」喵
- `BlockCollisions` 只扫实体周围 1 格的方块位置：玩家站顶时基座块（y=0）距其 2+ 格根本不被扫描，3 高包围盒对顶盖无效喵
- 修复：显式覆写 `getCollisionShape` 按 BE 锚点 y 层差裁剪高度 = `height - layer`；放置时在上层放**隐形碰撞格**（模型置空不可见），预检与 `onRemove` 联动破坏覆盖全部 `height` 层，三层拼成完整 3×3×3，每层在求解器可达范围内 → 顶部可站立喵

## 3. 渲染剔除（BER 余光消失）喵
- BER 视锥剔除基于**锚点格 1×1×1 默认渲染边界**，视线偏转（余光）时 BE 被判在视锥外→整颗消失（核心 3×3×3 余光消失根因，非背面 cull）喵
- 修复：渲染器 override NeoForge `IBlockEntityRendererExtension.getRenderBoundingBox(T)` 返回覆盖整组（可 inflate）的 AABB；注意 1.21.1 该方法在**渲染器**上加，BE 上加会编译错（参考 `PowerNodeBlockEntityRenderer`/`CoreBlockEntityRenderer`）喵
