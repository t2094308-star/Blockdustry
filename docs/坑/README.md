# 坑文档库（docs/坑）喵

> 按主题分类的坑记录。**子 agent 处理任务时只读相关主题文件，不要全文通读**（像 skill 一样按需加载）喵。
> **每次踩到新坑或修复后，必须更新对应主题文件**（或新增主题），为未来大规模并行迁移打基础喵。

## 索引：任务类型 → 读哪个文件喵

| 任务类型 | 读这个文件 |
|---|---|
| BER / 手绘 quad / 渲染器 / 光照 / overlay | `BER渲染.md` |
| 方块模型 JSON / blockstate / UV / 跨格 corner | `方块模型.md` |
| 碰撞箱 / 多格 AABB / 顶部站立 | `碰撞箱.md` |
| 贴图资源 / 比例 / 命名 / 透明底 | `贴图.md` |
| 队伍染色 / 队伍数据同步 | `队伍染色.md` |
| 附身 / 相机 / 视角 / freecam | `附身与相机.md` |
| Jade 联动 / 进度条 / 各类条 | `Jade联动.md` |
| 炮弹 / 实体 / 伤害 / 装甲 | `炮弹与实体.md` |
| 建筑间物品交接 / directionOf / dumpItem | `物流交接.md` |
| MC/NeoForge API 签名 / SavedData / 编译与 Gradle 缓存 | `API签名与编译.md` |

## 专项坑文档喵

- `炮管黑.md`（entityCutout 透传 light 白天极暗压黑）
- `PowerNode激光黑色.md`（setOverlay(0xFFFFFF) 越界采样染黑）
- `炮塔黑色阴影.md` / `炮塔黑色阴影2.md`（多 quad 共面渗色 / 底座模型侧面深色）
- `机器侧面贴图.md`（侧面贴图内容错误：拿顶面局部当侧面）
- `Jade条颜色黑灰修复.md`（ProgressView.read 默认 style 非 null）

## 使用规则喵

1. 处理任务前：根据任务类型读对应主题文件（+ 相关专项）
2. 出错修复后：把新坑/修复补进对应主题文件
3. 新主题：新建文件并在此 README 加索引行
4. 玩家可见文本不带「喵」字；注释可带喵
