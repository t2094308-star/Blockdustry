# 坑：方块模型 JSON / blockstate / UV 喵

## 1. 方块模型元素坐标上限 [-16,32] 喵
- element 的 from/to 坐标只能在 [-16,32]，`to.y` 超 32（如 48）导致整个模型**加载失败**，方块黑紫/透明（核心 3×3×3 曾触发）喵
- 想要多格高视觉方块**不能靠模型增高**，用 BER 或实体渲染喵

## 2. 方块模型置空的后果 喵
- 模型 elements 置空 → 方块自身不渲染（黑/透明），且可能失去正常碰撞表现；需 BER 补画 + 显式 `getShape`/`getCollisionShape`（见 `碰撞箱.md`）喵

## 3. UV 是 16×16 模型空间，不是贴图像素 喵
- face `uv` 范围 **0..16**，`[0,0,16,16]` = 整张贴图，MC 按贴图在方块 atlas 的位置自动映射喵
- **坑**：改成 `[0,0,64,64]` → 采样 atlas 左上 64×64 区域（钻石/金块等拼图）→ 侧面杂乱 + 卡顿喵
- 永远用 `[0,0,16,16]`；贴图分辨率越高越清晰（512 安全，别超 1024 atlas 上限）喵

## 4. 多格建筑跨格贴图 corner 喵
- 多格建筑（size≥2）用 `BlockdustryBuildingBlock.Corner`：2×2 四值（NW/NE/SW/SE）、3×3 九值（NW,N,NE,W,C,E,SW,S,SE）；`cornerFor(dx,dz)` 需**尺寸感知**喵
- blockstate 必须覆盖枚举全部 corner variant，否则未定义 variant 黑紫喵
- 模型顶面按象限裁剪（3×3 每格裁 1/3），UV 必须在贴图范围内喵

## 5. Mindustry 贴图朝向 喵
- Mindustry 贴图原始朝**东**（MC 模型默认朝北），blockstate 旋转映射：north=270/east=0/south=90/west=180 喵
